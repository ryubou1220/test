# 時間管理の記事 → 動画

- `out/time_management.mp4` … 完成動画（1920x1080・約2分30秒・BGM付き・ナレーションなし）
- `out/time_management.srt` … 字幕ファイル（YouTube などにアップロード可）
- `out/thumbnail.png` … サムネイル
- `narration.md` … ナレーション台本と投稿用の説明文
- `make_video.py` … 動画を作り直すスクリプト（`python3 video/make_video.py`）

文言を変えたいときは `make_video.py` の `SCENES` を編集して再実行してください。
