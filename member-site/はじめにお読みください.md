# コンテンツ・フリーダム　会員サイト　設置と更新のしかた

## このフォルダの中身
- `index.html` …… 会員サイトの本体（ホーム／講義／特典・教材／Q&A／質問する／ご利用案内）
- `files/` ……… 講義資料・特典・受講ガイド・図解・一括ZIP（ダウンロードサイトと同じもの）
- `htaccess_sample.txt` …… パスワード設定の見本

## 1. サーバーに置く
1. フォルダの中身をすべて、レンタルサーバーの公開フォルダ（例：`/member/`）にアップロードします。
2. サーバーの管理画面の「アクセス制限（ベーシック認証）」で、そのフォルダにIDとパスワードをかけます。
   - 管理画面に機能がない場合は、`htaccess_sample.txt` を使います。
3. 会員サイトのURL・ID・パスワードを、インフォトップの購入者向けの案内（ダウンロードファイルやサンクスページ）に書きます。

> パスワードは全員共通です。転売や共有が心配なときは、半年に一度などパスワードを変え、受講中の方にお知らせで案内してください。

## 2. 質問フォームをつくる（Googleフォーム・無料）
1. Googleフォームで新しいフォームを作ります。おすすめの項目：
   - どの講義・教材についての質問か（プルダウン：第1講義〜第7講義、特典、その他）
   - 質問の内容（段落）
   - Q&Aへの掲載（ラジオボタン：掲載してよい／掲載しないでほしい）
   - ※お名前やメールアドレスは集めなくて大丈夫です（回答はサイトに載せるため）。
2. 「送信」→「＜＞（埋め込み）」を選び、表示されたコードの `src="…"` の中のURLをコピーします。
3. `index.html` の `SUPPORT.formUrl` に貼り付けます。
4. 回答の通知は、フォームの「回答」タブ →「︙」→「新しい回答についてのメール通知を受け取る」でオンにできます。

## 3. 質問に答える（Q&Aに載せる）
`index.html` の `const QA = [` のすぐ下に、1件ずつ足していきます。新しいものを上にすると見つけやすくなります。

```
  { cat: "商品づくり", date: "2026-12-01", q: "（届いた質問を、個人がわからない形に整えて）", a: "（回答）" },
```

- `cat` は、すでにある分類（商品づくり／安心とルール／集客と販売／取り組み方）か、新しい分類名
- 質問をそのまま載せず、名前や個人が特定できる内容は外してください

## 4. お知らせを出す
`const NEWS = [` のすぐ下に足します。

```
  { date: "2026-12-01", text: "第4講義の講義資料を改訂しました。" },
```

## 5. 動画・教材を差し替える
- 動画：`LECTURES` の `video` を新しいURLに書き換えます（YouTubeは「限定公開」に）。
- 教材：`files` フォルダの同じ名前のファイルを上書きします。

## メモ
- 「受講済み」のチェックは、受講者のパソコンやスマホのブラウザに保存されます（サーバーには残りません）。端末を変えると、記録は引き継がれません。
- PDFは、パソコンではサイトの中で開き、スマホでは標準のPDF表示で開きます。
