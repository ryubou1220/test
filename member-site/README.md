# 会員サイト（WordPress）設定手順

日曜大工プログラムの購入者だけが入れる会員サイトを、WordPress に作る手順です。

- `preview.html` … 全ページの見た目を1枚で確認できます（動画は仮の枠）
- `src/member.css` … 見た目の指定。WordPress の「追加CSS」に1回だけ貼ります
- `pages/*.html` … 各ページの中身。「カスタムHTML」ブロックに貼ります
- 中身を直したら `python3 member-site/src/build.py` で作り直せます

## 全体の流れ

```
Infotopで購入 → 購入完了メールの「商品URL」＝会員登録ページ
→ 購入者が登録 → あなたが注文を確認して承認 → 会員ページを見られる
```

## 1. プラグインを入れる

1. 管理画面「プラグイン → 新規追加」で **Simple Membership** を検索し、インストールして有効化します。
2. 「WP Membership → 設定」を開きます。
   - **一般設定**：「無料会員登録を有効にする」にチェック。会員レベル（次の手順で作るもの）のIDを入れます。
   - **詳細設定**：「会員の手動承認を有効にする」にチェック。これで、購入していない人が登録しても中は見られません。
   - 画面の名前はバージョンで多少違います。迷ったら「free membership」「manual approval」で検索してください。
3. 「WP Membership → 会員レベル」で、レベルを1つ作ります（名前：日曜大工プログラム、期間：無期限）。

## 2. 見た目（CSS）を入れる

「外観 → カスタマイズ → 追加CSS」に、`src/member.css` の中身をすべて貼って公開します。
（ブロックテーマの場合は「外観 → エディター → スタイル → 追加CSS」）

## 3. ページを作る

ページを作り、ブロックの「＋」から **カスタムHTML** を選び、対応するファイルの中身を丸ごと貼ります。

| ページ名 | スラッグ | 貼るファイル | 会員限定 |
|---|---|---|---|
| 会員登録 | register | pages/00-register.html | いいえ |
| ログイン | login | pages/01-login.html | いいえ |
| 会員トップ | member | pages/10-top.html | はい |
| STEP1 計画する | step1（親：会員トップ） | pages/11-step1.html | はい |
| STEP2 そろえる | step2（親：会員トップ） | pages/12-step2.html | はい |
| STEP3 基礎をつくる | step3（親：会員トップ） | pages/13-step3.html | はい |
| STEP4 骨組みを組む | step4（親：会員トップ） | pages/14-step4.html | はい |
| STEP5 天板を張って塗る | step5（親：会員トップ） | pages/15-step5.html | はい |
| STEP6 長持ちさせる | step6（親：会員トップ） | pages/16-step6.html | はい |
| 資料ダウンロード | downloads（親：会員トップ） | pages/20-downloads.html | はい |
| 相談・質問 | support（親：会員トップ） | pages/21-support.html | はい |
| 返金保証 | guarantee（親：会員トップ） | pages/22-guarantee.html | はい |

- STEP以降のページは、右の設定欄「ページ属性 → 親ページ」で「会員トップ」を選びます。アドレスが `/member/step1/` のようになり、ページ内のリンクがそのまま使えます。
- **会員登録**ページは、カスタムHTMLの下に「ショートコード」ブロックを足して `[swpm_registration_form]` と入れます。
- **ログイン**ページも同じように `[swpm_login_form]` を入れます。
- 「会員限定：はい」のページは、編集画面の下にある「Simple WP Membership Protection」で「保護する」にチェックし、作った会員レベルにチェックを入れます。
- 会員限定ページは、検索結果に出ないように「設定 → 表示設定」ではなく、SEOプラグインのページ単位の設定で「noindex」にしておくと安心です。

## 4. 差し替える所

貼ったあと、ページ内の次の文字を書き換えます（ブラウザの検索で「［」を探すと見つかります）。

| 書いてある文字 | 入れるもの | 場所 |
|---|---|---|
| `ここに動画ID_intro` / `ここに動画ID_step1` 〜 `step6` | YouTube の動画ID | 会員トップ・各STEP |
| ［LINE公式のURL］ | LINE公式アカウントの友だち追加URL | ほぼ全ページ |
| ［メールアドレス］ | 相談用のメールアドレス | 相談・質問、返金保証 |
| ［かんたん版PDFのURL］ / ［完全版PDFのURL］ | メディアに上げたPDFのURL | 資料ダウンロード |
| ［計算ツールのURL］ | 計算ツールのURL | 資料ダウンロード |
| 【ここに、記述済みの「返金保証の詳細」…】 | 書き済みの返金条件と手続き | 返金保証 |
| 【要確認：…】 | 返信日数・承認までの日数 | 会員登録、相談・質問 |

**YouTube の動画ID**：動画のURL `https://youtu.be/AbCdEf12345` の、最後の `AbCdEf12345` の部分です。動画は「限定公開」にしてください。

**PDFの置き場所**：メディアに上げたPDFは、URLを知っていればだれでも開けます。ファイル名を推測されにくい名前（例：`deck-manual-k7q2.pdf`）にしておくと安心です。

## 5. Infotop に登録する

Infotop の商品設定で、購入者に案内する「商品URL」（ダウンロード先）に、**会員登録ページのURL**（例：`https://あなたのブログ/register/`）を入れます。

注文が入ったら、「WP Membership → 会員」で、Infotop の注文一覧と同じメールアドレスの人を「有効」にします。

## 6. 公開前の確認

1. ログアウトした状態（別のブラウザやシークレットウィンドウ）で `/member/` を開き、中が見えないことを確かめます。
2. テスト用のメールアドレスで登録し、承認してからログインして、全ページの動画・ボタン・リンクを確かめます。
3. スマホでも同じ確認をします。
