# ソフトボールチーム 三日会 ホームページ

`index.html` をブラウザで開くと表示できます（`style.css` と `script.js` も同じフォルダに置いてください）。

## 内容の編集
`index.html` の中に「ここに追加してください」とコメントがある場所を編集します。

- **チーム紹介**: 結成年・活動日・活動場所などの「○○」を書き換え
- **お知らせ / 試合日程 / 試合結果 / メンバー**: 既存の項目をコピーして追加
- **ギャラリー**: `images/` フォルダに写真を置き、`<div class="placeholder">` を `<img src="images/xxx.jpg" alt="説明">` に差し替え
- **お問い合わせ**: `mailto:example@example.com` を実際のメールアドレスに変更
- **色**: `style.css` 冒頭の `:root` の値を変更

## 公開方法（GitHub Pages）
リポジトリの Settings → Pages で公開するブランチとフォルダ（`/ (root)`）を選ぶと公開されます。
