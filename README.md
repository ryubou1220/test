# 新生弓木神楽組 情報共有サイト

弓木神楽保存会 新生弓木神楽組の、組員・関係者向け情報共有サイトです。

## 内容の更新方法

お知らせ・予定・連絡事項・連絡先は **`data/site-data.js` だけ**を編集すれば更新できます。
GitHub 上でファイルを開き、鉛筆アイコン（Edit）から直接書き換えて保存（Commit）してください。

- 日付は `"2026-12-01"` の形式
- 予定の `type` は `"稽古"` / `"奉納"` / `"会合"` のいずれか
- 「（要記入）」の箇所は実際の情報に置き換えてください

日付が過ぎた予定は自動で「終わった予定」に移り、直近の予定がトップに表示されます。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages で、公開するブランチとフォルダ（`/ (root)`）を選ぶと公開されます。
ローカルでは `index.html` をブラウザで開くだけで確認できます。

## 構成

- `index.html` … ページ本体
- `data/site-data.js` … 掲載内容（ここを編集）
- `assets/style.css` … デザイン
- `assets/main.js` … 表示処理

## 組員専用ページ（出欠入力）

`members/kagura-members.html` は claude.ai 上で公開している組員専用ページの元ファイルです。
予定・お知らせ・出欠のデータはページ側のデータベースに保存されるため、内容の更新はページ上の「編集」から行います。

## Word版
