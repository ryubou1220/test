# 電子書籍をブログ記事で1冊目を出す

サロン・ひとりビジネスを営む女性向けの電子書籍原稿です。
書きためたブログ記事をもとに1冊目の電子書籍（Kindle）を出す方法を解説し、巻末で著者の出版サポートへご案内する構成になっています。

- 原稿：[book/電子書籍をブログ記事で1冊目を出す.md](book/電子書籍をブログ記事で1冊目を出す.md)
- Word版：[book/電子書籍をブログ記事で1冊目を出す.docx](book/電子書籍をブログ記事で1冊目を出す.docx)
- 出版用の内容紹介・キーワード：[book/出版用_内容紹介とキーワード.md](book/出版用_内容紹介とキーワード.md)

## 表紙（book/表紙/）

KDP推奨サイズ（1600×2560ピクセル、縦横比1.6:1）のJPEG。3案から1つ選んでアップロードする。

- 表紙A_やわらかエレガント.jpg（明朝体・ピンクベージュ）
- 表紙B_ナチュラル.jpg（丸ゴシック・セージグリーン）
- 表紙C_インパクト.jpg（太ゴシック・深いプラム色）
- 表紙_3案比較.jpg
- _source/：元データ。`sh fetch_fonts.sh` でフォントを取得し、`node shot.js $PWD/cover.html $PWD/out` で書き出す。著者名は cover.html の「【著者名】」を書き換える

## 読者限定プレゼント（book/特典/）

- 特典1_ブログ記事棚卸し＆目次づくりテンプレート.xlsx（Excel／Googleスプレッドシート）
- 特典2_コンセプトが30分で決まる質問シート.pdf（A4・5ページ）
- 特典3_ブログ記事原石診断_申し込みシート.pdf（A4・1ページ／LINEで文章診断）
- 著者用_特典の配布とLINEメッセージ.md（配布手順・LINE文例・診断結果の書き方）
- _source/：特典の元データ（PDFは `node pdf.js` 、xlsxは `python3 mk_xlsx.py 出力先.xlsx` で再生成）

## 出版前に埋める項目

原稿内の `【 】` で囲まれた部分は、著者ご自身の情報に差し替えてください。

- 著者名・肩書き・経歴（はじめに／おわりに／著者プロフィール）
- 第9章 9-2 の著者自身の体験談
- 巻末「著者からのご案内」：プレゼント内容、合言葉、LINE公式アカウントのURL・QRコード
- 出版サポートのサービス名・期間・回数・形式

## 注意

KDP（KDPセレクトの独占ルール、ロイヤリティ条件、表紙サイズなど）の規約は変更されることがあります。出版前に公式ヘルプで最新情報を確認してください。
