# ひとりビジネス戦略室

個人事業主・ひとり社長のための戦略ダッシュボードです。ビルドもサーバーも要らず、`index.html` をブラウザで開くだけで使えます。

## できること

- **概要**：ビジョン、目標の進捗、KPI達成率、今週のフォーカス（進行中の施策をインパクト÷工数の高い順に表示）、直近の振り返りを1画面で確認できます
- **目標**：OKR形式で目標と主要な成果（KR）を管理し、チェックすると進捗が自動で計算されます
- **KPI**：売上・顧客数・作業時間などを日付つきで記録し、推移グラフと目標ラインで達成率を確認できます（「小さいほど良い」指標にも対応）
- **施策ボード**：アイデア／進行中／完了のカンバン（ドラッグ＆ドロップか ← → ボタンで移動）。インパクト・工数・期限・関連する目標を設定できます
- **週次レビュー**：うまくいったこと／課題／来週やること／手応えを記録します。1週間以上空くと概要画面でお知らせします

## データの保存

データはブラウザの localStorage に保存され、外部には送信されません。初回はサンプルデータが入っているので、編集や削除をして自分の内容に置き換えてください。
バックアップや別のPCへの移行には、右上の「書き出し」「読み込み」（JSON形式）を使います。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — スタイル（ダークモード・スマホ表示に対応）
- `app.js` — 動作とデータ管理
