## deck-calculator/ … 無料の材料・費用計算ツール

`deck-calculator/index.html` と、計算部分の `lib/deck-engine.js` で動きます（公開するときは2つとも、フォルダの位置関係を変えずに置く）。

- 幅・奥行き・高さを入れると、束柱・大引・根太・床板の本数、束石、ビス、塗料、防草シートと材料費の目安を計算
- 業者に頼んだ場合（ソフトウッド 4万円/㎡〜、ハードウッド 5万円/㎡〜）との差額を表示
- 上から見た骨組み図（束柱・大引・根太の位置）を表示
- 最後に「サイズ別図面」と「実践マニュアル＋180日サポート」へのリンク

### 書き換える場所

| 項目 | 場所 |
|---|---|
| リンク先 | `deck-calculator/index.html` の `CONFIG.manualUrl`（マニュアル）、`CONFIG.planUrl`（サイズ別図面。販売ページができたら差し替え） |
| 業者の相場・束の間隔・床板のすき間 | `lib/deck-engine.js` の `SETTINGS` |
| 木材の単価・定尺 | `lib/deck-engine.js` の `MATERIALS`（1mあたりの価格） |
| 束石・ビス・塗料などの単価 | `lib/deck-engine.js` の `OTHER` |

`lib/deck-engine.js` を書き換えると、計算ツールと図面セットの両方に反映されます。

価格はおおよその目安です。近くのホームセンターの価格に書き換えてください（画面上の「単価を自分の地域の価格に変える」でも一時的に変えられます）。

### 公開のしかた

- **GitHub Pages**：このリポジトリの Settings → Pages で公開すると `https://<ユーザー名>.github.io/<リポジトリ名>/deck-calculator/` で見られます。ブログからはリンクを貼ります。
- **自分のサーバー**：`deck-calculator/` と `lib/` を同じ階層にアップロードします。

### 計算の前提

- 束柱は最大900mm間隔、根太は455mm間隔（ウリンは400mm）
- 床板は建物と平行に張り、すき間5mm
- 大引・根太・床板は支点の上で継ぐように分け、定尺材からムダが少なくなるように切り出して本数を数える（床板・根太は予備1本）
- 束柱が300mm以上なら根がらみを入れる

## deck-plans/ … 販売用のサイズ別図面セット（PDF）を作るページ

`deck-plans/index.html` をパソコンのブラウザ（Chrome など）で開き、サイズと木材を選んで「印刷・PDFで保存」→ 送信先「PDFに保存」。A4・7ページのPDFができます。

1. 表紙・概要（骨組みの図、面積・部材数・材料費・作業日数、収録内容）
2. 基礎伏図（束石の位置と番号、左端・建物からの距離、直角を確かめる対角線の長さ）
3. 骨組み図（大引・根太の位置と間隔、固定のポイント）
4. 断面図（高さの内訳）と床板の割付（最後の1列を何mmに割くか）
5. カット表（定尺材ごとの切り方）
6. 購入リスト（チェック欄つき、道具と買うときの注意）
7. 3日間の作業手順（チェックリスト）

監修者名・サイトなどは `deck-plans/index.html` の `BRAND` で変えられます。
`deck-plans/samples/` に、ウエスタンレッドシダーの定番5サイズの見本PDFがあります（単価が目安のままなので、販売前に単価を直して作り直してください）。
