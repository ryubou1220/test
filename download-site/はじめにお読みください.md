# 受講者専用ダウンロードページの使い方

このフォルダ（`download-site`）をまるごとサーバーに置くと、受講者専用のダウンロードページになります。

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | ダウンロードページ本体 |
| `files/` | 教材（PDF・Word・図解・まとめZIP） |
| `htaccess_sample.txt` | パスワードをかけるための設定の見本 |

## 公開までの手順

1. **サーバーにアップロードする**
   お使いのレンタルサーバー（エックスサーバーなど）に、フォルダごとアップロードします。
   例：`https://あなたのドメイン/cf-member/`

2. **パスワードをかける（必ず行ってください）**
   有料の教材なので、購入者以外が見られないようにします。
   多くのレンタルサーバーには「アクセス制限」「ベーシック認証」という機能があり、管理画面からIDとパスワードを設定できます。
   管理画面で設定できない場合は、`htaccess_sample.txt` を参考にしてください。

3. **インフォトップに登録する**
   商品の「ダウンロードページ（商品URL）」として、このページのURLを登録します。
   IDとパスワードは、受講ガイドや購入後のご案内に書いておきます。

## 内容を変えるとき

`index.html` をメモ帳などで開き、上のほうにある `LECTURES`（講義）と `BONUSES`（特典）の部分だけを書き換えます。

- **動画のURL**：`video: ""` の `""` の中に、VimeoやYouTube（限定公開）のURLを入れます。
- **教材を差し替える**：`files/` の中の同じ名前のファイル（例：`bonus01.pdf`）を、新しいものに入れ替えます。
- 空欄のままのところは、ページ上で「準備中」と表示されます。
- 教材を増やしたら、`files/content-freedom-materials.zip` も作り直してください。

## いま「準備中」になっているもの

- 「困ったときは」欄の質問の方法・受付期間・返信の目安

講義動画（全7講義）、講義資料、受講ガイド、特典1〜8は、すべてそろっています。
動画はYouTubeの「限定公開」にしておくと、リンクを知っている購入者だけが見られます。

## 注意

- ページには検索エンジンに載らない設定（noindex）を入れていますが、それだけでは守れません。パスワードは必ずかけてください。
