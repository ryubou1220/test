# 購入者向けダウンロードページ

購入者が「ダウンロードコード」を入力すると、購入した商品のファイルが表示されるページです。
サーバーは不要で、GitHub Pages などにそのまま置けます。

## 仕組み

- ファイル本体は Google ドライブや販売サービスなど、別の場所に置きます。
- このページには、そのファイルのURLを **ダウンロードコードで暗号化したもの** だけを載せます。
- コードを知らない人がページのソースを見ても、URLはわかりません。

## 商品を追加・変更する手順

1. `tools/products.source.example.json` をコピーして `tools/products.source.json` を作る（初回のみ）
2. `tools/products.source.json` に商品名・ダウンロードコード・ファイルのURLを書く
3. 次のコマンドで `products.json` を作り直す

   ```bash
   node tools/make-products.mjs
   ```

4. `index.html` と `products.json` を公開する

`tools/products.source.json` にはコードとURLがそのまま入っているので、公開しないでください（`.gitignore` で除外済み）。

## 注意

- 同じ商品の購入者は全員同じコードを使います。コードが広まると、買っていない人もダウンロードできます。
  心配な場合は、定期的にコードとファイルのURLを変えてください。
- ファイル置き場のURL自体に誰でもアクセスできる設定だと、URLを知った人は直接ダウンロードできます。
- 公開前に、ページ上部の「これはサンプルです」の帯（`id="sample-note"`）を削除してください。
