# はじめての木工 4ステップ（ステップ配信のサンプル）

- `register.html` … STEP1（踏み台）の無料登録ページ。ブラウザで開けば確認できます
- `配信シナリオ.md` … 登録後に届く配信の流れ、印（タグ）のルール、メールの文面
- `src/register.html` … 確認用Webページに公開している元ファイル（中身は register.html と同じ）

## 公開前に差し替えるところ
- シリーズ名・講師名・プロフィール（ページ上で黄色く表示）
- 登録フォーム … UTAGE・MyASPなど配信サービスで作ったフォームの埋め込みコードに置き換える
- プライバシーポリシーのリンク
