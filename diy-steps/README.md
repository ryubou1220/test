# はじめての木工 4ステップ（WordPress＋メール配信＋インフォトップ）

無料のSTEP1（踏み台）を自分のWordPressで配り、STEP2〜4をインフォトップで販売するための一式です。

## ファイル
- `wordpress/register.html` … 無料登録ページ。WordPressにそのまま貼り付ける
- `wordpress/thanks.html` … お礼ページ（STEP1の受け取りと、STEP2〜4の紹介）。WordPressにそのまま貼り付ける
- `配信シナリオ.md` … 登録後に届くステップメール6通の文面と、配信サービスで設定すること
- `src/` … 確認用プレビュー（ブラウザで開くと見た目を確認できます。WordPressには使いません）

## WordPressへの設置手順
1. **PDFをアップロード**：STEP1の教材PDFを「メディア」→「新規追加」でアップロードし、URLを控える
2. **動画を用意**：解説動画をYouTubeに「限定公開」でアップロードし、「共有」→「埋め込む」のコードを控える
3. **お礼ページを作る**
   - 「固定ページ」→「新規追加」。タイトル例：「STEP1 教材受け取り」
   - ブロック「カスタムHTML」を追加し、`wordpress/thanks.html` の中身をすべて貼り付ける
   - 黄色の部分（PDFのURL、動画、インフォトップのURL、送信元アドレス）を差し替える
   - SEOプラグインなどで**検索エンジンに表示しない（noindex）**設定にし、メニューにも載せない
   - 公開して、ページのURLを控える
4. **メール配信サービスの設定**
   - 登録フォーム（お名前・メールアドレス）を作る
   - 登録後の移動先を、3のお礼ページのURLにする
   - `配信シナリオ.md` の6通をステップメールとして登録する
5. **登録ページを作る**
   - 「固定ページ」→「新規追加」。ブロック「カスタムHTML」に `wordpress/register.html` の中身をすべて貼り付ける
   - 「ここから」「ここまで」の間の見本フォームを、配信サービスのフォームの埋め込みコードに置き換える
   - シリーズ名・講師名・プロフィール・プライバシーポリシーのURLを差し替える
   - ページテンプレートは「1カラム」や「全幅」など、サイドバーのないものを選ぶ
6. **テスト**：自分のメールアドレスで登録し、お礼ページへの移動と1通目のメールが届くことを確かめる

## 注意
- カスタムHTMLブロックに `<style>` や `<script>` を貼れるのは、管理者権限のアカウントです
- 見た目のスタイルは `.diy-lp` の中だけに効くようにしてあるので、テーマのデザインは崩れません
