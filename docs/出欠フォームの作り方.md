# 出欠フォーム（Googleフォーム）の作り方

組員はアカウント不要で、リンクを開くだけで出欠を送れます。作る人だけGoogleアカウントが必要です。

1. https://forms.google.com を開き、「空白のフォーム」を作る
2. タイトル：「新生弓木神楽組 出欠連絡」
3. 質問を追加
   - **お名前**（記述式・必須）
   - **予定**（プルダウン・必須）… 例「12/6 定例稽古」「12/13 定例稽古」…　※予定が増えたら選択肢を追加
   - **出欠**（ラジオボタン・必須）… 出席 / 欠席 / 未定
   - **ひとこと**（記述式・任意）… 遅刻・早退など
4. 「設定」→「回答」で **「ログインが必要」をオフ**（「回答を1回に制限する」もオフ）にする
   → これで組員はGoogleアカウントなしで回答できます
5. 「回答」タブ →「スプレッドシートにリンク」で集計表を作る
6. 右上「送信」→ リンクのマーク →「URLを短縮」→ コピー
7. `data/site-data.js` の `attendance.formUrl` にそのURLを貼る

## 出欠状況を組員にも見せたい場合（任意）

集計スプレッドシートで「共有」→「リンクを知っている全員」を **閲覧者** にしてURLをコピーし、
`attendance.resultUrl` に貼ると「出欠状況を見る」ボタンが出ます。
（名前が見えるので、見せてよいか組で確認してください）
