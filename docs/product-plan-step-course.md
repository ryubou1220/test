# 商品改良案：小さな作品から始めて、最後はウッドデッキまで

## コンセプト

> **道具を持ったことがない人が、5つの週末で、ウッドデッキをつくれるようになる。**

「ウッドデッキのつくり方」を売るのではなく、**DIYができるようになる講座**を売る。
小さな作品を順番につくるうちに、ウッドデッキに必要な技術（切る・留める・張る・組む・基礎）が一つずつ身につき、最後の卒業制作がウッドデッキになる。

### なぜ変えるのか

| 今の商品 | 改良後 |
|---|---|
| ウッドデッキを作りたい人だけが対象（少ない） | DIYを始めたい人すべてが対象（多い） |
| いきなり大物なので「失敗が怖い」で止まる | 小さな成功を重ねるので、不安が自信に変わる |
| 1人1回きりの購入 | ステップごとに何度も買ってもらえる |
| 29,800円をいきなり払う | 無料・低価格から始められる |
| 春と秋しか売れない | 小さな作品は一年中つくれる |

販売ページの意識調査にある「ためらう理由」（工具がない、失敗が怖い、手順がわからない、相談できる人がいない）に、ステップ形式がそのまま答える。

## カリキュラム（案）

**つくった作品は、最後にウッドデッキの一部になる。** 踏み台はデッキの昇り口、ベンチはデッキの上、プランター台はデッキの脇に置ける。

| ステップ | 作品 | 身につく技術（デッキのどこで使うか） | 材料費 | 時間 |
|---|---|---|---|---|
| 1 | **踏み台** | 道具の使い方、まっすぐ・直角に切る、下穴とビス止め（すべての作業の基本） | 約3,000円 | 半日 |
| 2 | **プランター台（すのこ）** | 板をすき間をそろえて張る、治具を使う、ビスの位置をそろえる（床板張り） | 約4,000円 | 半日 |
| 3 | **縁台ベンチ** | 骨組みを組む、水平と直角（対角線）を確認する（大引・根太） | 約8,000円 | 1日 |
| 4 | **置くだけミニデッキ（90×90cm）** | 水糸を張る、束石を据えて高さをそろえる（基礎）。勝手口のステップとしても使える | 約15,000円 | 1〜2日 |
| 5 | **卒業制作：ウッドデッキ** | ステップ1〜4の総まとめ。サイズ別図面と180日サポートつき | 約10〜30万円 | 3日〜 |

※材料はステップ1から2×4材・2×6材・ウエスタンレッドシダーなど、デッキと同じ木材を使う。手に慣れた材料で本番に臨める。

## 今あるものの使い道

| 今あるもの | 使う場所 |
|---|---|
| 実践マニュアル（108ページ） | 章ごとに分けて各ステップへ。工具の章→ステップ1、床板張り→2、骨組み→3、基礎→4、残り→5 |
| 解説動画 | 同じく章ごとに分ける |
| 材料・費用計算ツール | ステップ5の入口。無料ステップの最後で紹介する |
| 図面セット（`deck-plans/`） | ステップ5の教材。同じ仕組みでステップ2〜4の図面も作れる |
| 180日サポート | ステップ5の主役 |
| お客様の声（I.Oさん、よしひろさん） | 卒業制作の実例として紹介 |
| フェンス・門扉・囲炉裏テーブルの経験 | 卒業後の追加コース（「次はフェンス」など） |

## SNSでの発信

各ステップの作品が、そのまま投稿ネタになる（完成写真、作業の30秒動画、受講者の作品紹介）。
ウッドデッキだけだと年に数回しか投稿できないが、ステップ形式なら毎週投稿できる。
