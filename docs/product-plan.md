# 商品企画書：「成功者の思考体系」×「結果を出す習慣」

## 1. 企画の要旨

「成功者の考え方」を学ぶ商品は多くありますが、**知って終わり（行動が変わらない）** という不満が根強くあります。
本企画では、次の2テーマを **「考え方（OS）」と「習慣（アプリ）」** の関係で1つのシステムとして提供します。

| テーマ | 役割 | 提供価値 |
|---|---|---|
| 成功者の思考体系 | 判断の土台（OS） | 何を選び、何を捨てるかの基準を持てる |
| 結果を出す習慣 | 日々の実行（アプリ） | 基準を毎日の行動に落とし込み、続けられる |

**コンセプト案：「考え方を、行動の仕組みに変える」**
キャッチコピー案：
- 「わかっているのに、できない」を終わらせる
- 成功者の頭の中を、あなたの1日のスケジュールに
- 意志の力に頼らず、結果が出る人になる

---

## 2. ターゲット

### メインターゲット
- **25〜45歳の会社員・個人事業主**
- 自己啓発書を何冊も読んだが、行動や成果が変わらなかった
- 副業、昇進、独立など「次の一歩」を考えている
- 時間がない（1日に使えるのは15〜30分）

### ペルソナ例
> 34歳・営業職。ビジネス書を年20冊読むが、読んだ直後にやる気が出るだけで3日後には元通り。
> 「自分は意志が弱い」と思っている。副業を始めたいが、何から手をつけるか決められない。

### 抱えている悩み → 提供する解決
| 悩み | 解決 |
|---|---|
| 学んでも行動に移せない | 毎日の具体的な行動テンプレートを渡す |
| 三日坊主で続かない | 習慣化の仕組み（トリガー設計・記録・仲間） |
| 優先順位がつけられない | 成功者に共通する意思決定フレームを教える |
| 自分に合うやり方がわからない | 診断で自分のタイプを知り、合う方法を選ぶ |

## 3. コンテンツの骨格（共通カリキュラム）

### Part A：成功者の思考体系（7つの原則）
1. **目的思考**：手段より「何のためか」から逆算する
2. **当事者意識**：環境のせいにせず、自分が変えられる部分に集中する
3. **長期視点**：短期の快楽より、複利で効くものに投資する
4. **選択と集中**：「やらないこと」を先に決める
5. **仮説と検証**：完璧を待たず、小さく試して修正する
6. **失敗の再定義**：失敗をデータとして扱う
7. **与える姿勢**：信頼と人脈を資産として育てる

### Part B：結果を出す習慣（毎日・毎週・毎月の型）
| 頻度 | 習慣 | 所要時間 |
|---|---|---|
| 毎朝 | 今日の最重要タスクを1つ決める | 5分 |
| 毎日 | 最重要タスクに集中する時間を確保する（ディープワーク） | 25〜90分 |
| 毎晩 | 3行日記（できたこと／学び／明日の一手） | 5分 |
| 毎週 | 週次レビュー（振り返りと次週の計画） | 30分 |
| 毎月 | 目標の見直しと、捨てることの棚卸し | 60分 |

### Part C：続けるための仕組み
- 「もし◯◯したら、△△する」型のトリガー設計
- 最初は「2分でできる」まで小さくする
- 習慣トラッカーで記録して可視化する
- 仲間や伴走者がいる環境をつくる

> ※各原則・習慣には、実際の成功者のエピソードや研究知見を出典付きで添え、根拠のある内容にする。

| ② 入口 | 『結果を出す人の7つの思考と習慣』 | 電子書籍／小冊子 | 500〜1,500円 | 信頼の獲得・世界観を伝える |

### 主力商品④「30日 実践プログラム」の詳細
| 週 | テーマ | 内容 |
|---|---|---|
| 0日目 | 準備 | 診断・目標設定・現状の記録 |
| 1週目 | 土台を整える | 目的思考・やらないことリスト・朝の5分習慣 |

| 3週目 | 行動量を増やす | 仮説と検証・小さく試す・失敗の記録 |

- 毎日：5〜10分の動画と1つのワーク

- 修了特典：修了証、成果発表会、「結果習慣クラブ」初月無料

## 5. 差別化ポイント

| 一般的な自己啓発商品 | 本企画 |
|---|---|
| 考え方を「知る」まで | 考え方を「毎日の行動」まで落とし込む |
| 精神論・根性論 | 意志に頼らない、仕組みで続ける |
| 万人向けの一律な方法 | 診断にもとづくタイプ別のやり方 |
| 一回買って終わり | 記録・仲間・レビューで継続を支える |
| 成功者の体験談のみ | 体験談＋研究知見で根拠を示す |

**診断のタイプ案**（4タイプ）
- 戦略家タイプ：計画は得意だが、動き出しが遅い
- 行動家タイプ：すぐ動くが、方向がぶれやすい
- 完璧主義タイプ：質は高いが、量とスピードが足りない
- 協調タイプ：人のためには動けるが、自分の目標が後回しになる

## 6. 集客・販売の流れ

```
SNS（X・Instagram・YouTubeショート）／ブログ・note
        ↓
無料診断 ①（メールアドレス・LINE登録）
        ↓
7日間のステップ配信 ＋ 電子書籍 ②
        ↓
無料オンライン説明会（60分）
        ↓
30日プログラム ④ の販売 ─→ 修了者に月額クラブ ⑤／個別コーチング ⑥
```

### 発信テーマ例
- 「成功者が毎朝5分でやっていること」
- 「やることリストより『やらないことリスト』が大事な理由」
- 「三日坊主は意志の問題ではない」
- 受講生のビフォー・アフター（本人の同意を得て掲載）

## 9. リスクと対策

| リスク | 対策 |
|---|---|
| 「怪しい情報商材」と見られる | 根拠（出典・研究）を明示する、返金保証を設ける、講師の経歴と実績を正直に公開する |
| 誇大な表現による法令違反 | 「必ず稼げる」「年収◯倍」などの断定や保証をしない。景品表示法・特定商取引法に沿った表記（特商法表記、返品・解約条件）を用意する |
| 体験談の扱い | 本人の同意を得る。「個人の感想であり、成果を保証するものではない」と明記する |
| 受講者が途中でやめる | 毎日の課題を10分以内にする、仲間と進める仕組み、遅れた人向けの追いつき週を設ける |
| 似た商品との競合 | 「診断×仕組み化×伴走」の組み合わせと、修了率の高さで差別化する |
| 心の不調を抱える人が参加する | コーチングの対象範囲を明示し、必要に応じて専門機関を案内する |

## 10. 立ち上げの計画

| 時期 | やること |
|---|---|
| 1か月目 | 診断の設問とタイプ設計、電子書籍の執筆、SNSでの発信開始 |

## 11. 次に決めること

1. **講師・発信者は誰か**（本人の実績やストーリーが、商品の説得力を左右します）
2. **主な販売チャネル**（自社サイト／Udemyなどの講座サイト／Kindle）
3. **価格帯の方針**（手に取りやすさ重視か、伴走の手厚さ重視か）
4. **試験版に参加してもらう最初の10〜20人をどう集めるか**
