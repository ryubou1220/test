# 商品企画書：りゅう坊が見てきた「成功者の思考体系」と「結果を出す習慣」

> この企画書は、メンターとして成功者のすぐ近くで過ごしてきた「りゅう坊」の目線で書いています。
> 【 】の部分は、りゅう坊本人の実際の経歴や数字に置き換えてください。

---

## 0. はじめに：なぜ「りゅう坊の目線」なのか

成功している人ほど、自分の成功について多くを語りません。
これまで【◯年間】、【経営者・起業家・トップ営業など◯人】のそばで過ごしてきて、私はそう実感しています。

語らない理由は、大きく4つあると見ています。

| 理由 | 私が見てきた様子 |
|---|---|
| **自覚がない** | 本人にとっては「当たり前」なので、何が特別なのかわかっていない |
| **言葉にしない** | 考えるより先に体が動いていて、手順として説明したことがない |
| **自慢に聞こえるのを嫌う** | 「運が良かっただけ」「周りのおかげ」で話が終わってしまう |
| **語る時間を使わない** | その時間があれば、次の一手に使う |

だから、本人の口から出てくる「成功の秘訣」は短くて抽象的です。
本当に大事なのは、**口にしないまま毎日くり返している、考え方と行動のクセ**のほうです。

私はそれを、本人ではなく**隣で見てきた第三者**として言葉にし、誰でも試せる形にまとめたいと考えています。
これが、この商品の出発点です。

## 1. 企画の要旨

**コンセプト：「成功者が語らないことを、隣で見てきた人が語る」**

| テーマ | 中身 | 受講者が得るもの |
|---|---|---|
| 成功者の思考体系 | 成功者が口にしない「判断の基準」 | 迷ったときに何を選ぶかの物差し |
| 結果を出す習慣 | 成功者が当たり前にくり返す「毎日の型」 | 意志の強さに頼らず続けられる仕組み |

キャッチコピー案：
- 成功者は、自分の成功を語らない。だから、隣で見てきた私が語ります。
- 本には書かれない「成功者の当たり前」
- 「すごい人」ではなく、「すごい人の毎日」を真似する

---

## 2. どんな人に届けたいか

### メインターゲット
- **25〜45歳の会社員・個人事業主**
- 成功者の本や講演にふれても、「で、明日から何をすればいいの？」で止まってしまう
- 副業、昇進、独立など「次の一歩」を考えている
- 1日に使えるのは15〜30分

### 私がこれまで見てきた「伸び悩む人」の特徴
成功者だけでなく、伸び悩む人もたくさん見てきました。両者の差は、才能より**日々の小さな選び方**にあると感じています。

| 伸び悩む人がやりがちなこと | 成功者が黙ってやっていること |
|---|---|
| 学ぶことで満足する | 学んだその日に、小さく1つ試す |
| やることを増やし続ける | やらないことを先に決める |
| 失敗を隠す、引きずる | 失敗をメモして、次の材料にする |
| 気分が乗るのを待つ | 気分と関係なく、始める時間を決めている |
| 人に何をしてもらえるかを考える | 先に自分から何かを差し出す |

## 3. コンテンツの骨格

### Part A：成功者の思考体系 ― 「言わないけれど、やっていること」7つ

各原則は「成功者が口にすること」と「実際にやっていること」のギャップとして伝えます。

| # | 原則 | 成功者が口にすること | 私が隣で見た、実際にやっていること |
|---|---|---|---|
| 1 | 目的思考 | 「特に深く考えてないよ」 | 動く前に必ず「これは何のため？」と一度だけ問い直している |
| 2 | 当事者意識 | 「運が良かっただけ」 | うまくいかないとき、まず「自分が変えられる部分」から手をつけている |
| 3 | 長期視点 | 「目の前のことをやってるだけ」 | 健康・学び・人間関係など、すぐ結果が出ないものに毎日少しずつ時間を使っている |
| 4 | 選択と集中 | 「たまたま断っただけ」 | 魅力的な誘いでも、軸から外れるものははっきり断っている |
| 5 | 仮説と検証 | 「とりあえずやってみた」 | 「とりあえず」の前に、小さな予想を立ててから試している |
| 6 | 失敗の再定義 | 「失敗なんてしょっちゅうだよ」 | 失敗の直後に、原因と次の一手を短く書き残している |
| 7 | 与える姿勢 | 「周りの人のおかげ」 | 見返りを求めず、人を紹介したり情報を渡したりしている |

> 登場する成功者のエピソードは、本人が特定されないように加工し、可能な限り本人の了承を得て使います。

### Part B：結果を出す習慣 ― 私が見てきた「毎日の型」

| 頻度 | 成功者がやっていた習慣 | 受講者向けの形 | 所要時間 |
|---|---|---|---|
| 毎朝 | 誰とも話す前に、今日いちばん大事なことを決めている | 朝いちばんに「今日の1つ」を書く | 5分 |
| 毎日 | 予定表に「誰にも邪魔させない時間」を先に入れている | 集中する時間を予定として確保する | 25〜90分 |
| 毎晩 | 寝る前に一日を短く振り返っている | 3行日記（できたこと／学び／明日の一手） | 5分 |
| 毎週 | 週末に1人で考える時間をとっている | 週次レビュー | 30分 |
| 毎月 | 定期的に「やめること」を決めている | 目標の見直しと「やめることリスト」 | 60分 |

### Part C：続けるための仕組み
成功者の多くは「自分は意志が強い」とは思っていません。続けられる環境を先につくっています。
- 「もし◯◯したら、△△する」というきっかけを決める
- 最初は「2分でできる」まで小さくする
- 記録して、続いていることを目で見えるようにする
- 一緒に取り組む仲間や、見てくれる人をつくる

## 5. 他の商品との違い

| よくある成功本・講座 | この商品 |
|---|---|
| 成功者本人の自伝・自己語り | **隣で見てきた第三者**が、本人も気づいていない部分を言葉にする |
| 1人の成功体験 | **複数の成功者に共通するパターン**と、伸び悩む人との違い |
| 結果だけが語られる | 結果に至るまでの**地味な毎日**を見せる |
| 精神論・根性論 | 意志に頼らない、仕組みで続ける |
| 一律のやり方 | 診断にもとづくタイプ別のやり方 |

**診断のタイプ案**（りゅう坊が見てきた成功者を4タイプに整理）
- 戦略家タイプ：じっくり計画してから一気に動く
- 行動家タイプ：まず動いて、走りながら考える
- 職人タイプ：一つのことを深く磨き続ける
- 人脈タイプ：人とのつながりからチャンスをつくる

各タイプについて「このタイプの成功者は、こんな習慣を持っていた」とりゅう坊が解説し、受講者が真似しやすい方法を選べるようにします。

## 9. リスクと対策

| リスク | 対策 |
|---|---|
| 登場する成功者のプライバシー | 名前・会社・業種・時期などを加工し、本人が特定されないようにする。可能な限り本人の了承を得る。守秘義務のある話は使わない |
| 「本当に見てきたの？」と疑われる | りゅう坊の経歴（【メンター歴・関わった人数・立場】）を具体的かつ正直に示す。了承を得られた成功者には推薦の言葉をもらう |
| 「怪しい情報商材」と見られる | 誇張しない語り口、返金保証、根拠（研究や出典）の併記 |
| 誇大な表現による法令違反 | 「必ず稼げる」「年収◯倍」などの断定や保証をしない。景品表示法・特定商取引法に沿った表記（特商法表記、返品・解約条件）を用意する |
| 体験談の扱い | 本人の同意を得る。「個人の感想であり、成果を保証するものではない」と明記する |
| 受講者が途中でやめる | 毎日の課題を10分以内にする、仲間と進める仕組み、遅れた人向けの追いつき週を設ける |
| 心の不調を抱える人が参加する | メンタリングの対象範囲を明示し、必要に応じて専門機関を案内する |
