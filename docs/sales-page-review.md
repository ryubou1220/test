## 読者を遠ざけている言葉（削除・修正をおすすめ）

1. 「価格面だけで『自分でやれば安価でできるだろう』という思考でやるのであれば、正直考え直す必要があります」
   → 見出しで「格安」とうたっているのに、安くしたい人を断っています。**読者の一番の動機を否定しない**。
2. 「長期間的にみると…決してお安くないものにはなります」 → 不安を増やすだけなので削除。
3. 「￥50,000（税込）で設定したいと…と言いたいところなのですが…」
   → 情報商材でよく使われる値引き演出です。DIYをする家族層には逆に警戒されます。削除して価格をそのまま示す。
4. ものづくりの歴史・大和言葉・AIの時代の話、メーカーのメンテナンスフリー論、意識調査の長い引用
   → デッキを作りたい人には関係が薄く、ここで離脱します。3〜4行に縮めるか削除。
5. 「おうち時間がふえたことにより」 → コロナ期の言い方で、ページが古く見えます。
6. 「本気のあなただけに」「一括払いをお願いしています」（直後にカード分割の注意書きがあり矛盾）

## 返金保証が使いにくく見える

- 返金できるのは「購入後180日を過ぎてから30日以内」だけ
- 身分証・実践した証明画像などの提出が必要
- 実践前の返品は「理由をお聞かせいただく必要」

→ 「**180日サポートを受けても完成しなければ全額返金。メール1通で受け付けます**」くらいまで簡単にすると、保証が安心材料として効きます。
