# ウッドデッキ実践マニュアル かんたん版の構成案

今のマニュアル：108ページ、オープニング＋10ステップ＋クロージング（2020年版の目次より）
かんたん版の目標：**約30ページ**、6ステップ。読む本ではなく、**作業しながら見る本**にする。

## かんたんにする4つのルール

1. **ステップを作業の順番どおりに6つにまとめる**（3日間の作業の流れと同じにする）
2. **計算はツールと図面に任せる**：材料の拾い出し・枚数計算・根太の割付け・一覧表づくりは、計算ツール（`deck-calculator/`）とサイズ別図面（`deck-plans/`）が自動で出す。本文からは外す
3. **1ページ＝1つの作業**：各ページは「図1枚＋やること3つ＋チェック＋よくある失敗」の形にそろえる
4. **知識の話は巻末の「付録」へ**：工具の詳しい説明、木材の種類、塗料の比較などは、読みたい人だけが読めばよい

## 新しい目次（案）

| 新しいステップ | 内容 | ページ | 今のマニュアルのどこから |
|---|---|---|---|
| はじめに | この本の使い方、3日間の流れ（1枚の図） | 2 | オープニング（ためらう理由・解決策・時間と手間）を1ページに |
| **1 計画する** | 場所と大きさを決める → 計算ツールで材料と費用を出す → 図面を用意する | 4 | step1（場所・図面・予算・日程）、step2（パターン・枚数）、step3（測る・拾い出し・一覧表） |
| **2 そろえる** | 購入リストで材料を買う、道具をそろえる、置き場の確保 | 3 | step1（工具をそろえる）、step4（材料の選択と購入・余裕をもって注文・置き場） |
| **3 基礎をつくる**（1日目） | 水糸を張る、対角線で直角、束石を据える、高さをそろえる、束柱を立てて垂直を見る | 6 | step3（束石の位置出し）、step5（束石・直角・高さ・傾斜地・支柱・垂直・水平器） |

| **6 長持ちさせる** | 日常点検・定期点検、再塗装の目安、点検チェックリスト | 2 | step8（劣化しやすい箇所・再塗装の目安）、step9 すべて |
| 付録 | 工具の使い方と安全（キックバック）、木材の種類と特性、塗料の種類と価格、あると便利な道具 | 4 | step1（工具の用途・電動工具・キックバック）、step4（樹種・板目と柾目・豆知識・塗料・セメント）、step10 |
| おわりに | 完成したら、次はフェンス・ベンチへ | 1 | クロージング |

合計 約33ページ

## 1ページの形（例：3-2 対角線で直角を確かめる）

```
┌────────────────────────────┐
│ 3-2 対角線で直角を確かめる       1日目 │
│ ┌──────────────┐                     │
│ │   図（水糸と対角線）  │  やること           │
│ └──────────────┘  ① 外周に水糸を張る   │
│                      ② 対角線を2本測る    │
│                      ③ 同じ長さになるまで直す│
│ □ チェック：2本の差が5mm以内                │
│ ⚠ よくある失敗：杭がゆるんで水糸がずれる      │
│ ▶ あなたの家の対角線の長さは、図面セットの2ページ │
└────────────────────────────┘
```

## 外すもの・短くするもの

- 「ためらう理由」「解決策を思考する」などの考え方の話 → 「はじめに」の1ページだけにする
- 材料の枚数・根太の延長・注文数の計算例 → 計算ツールと図面に置き換える
- 工具の用途・コスト・豆知識、木材の種類、塗料の価格比較 → 付録にまとめて短くする
