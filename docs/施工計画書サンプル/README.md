# 施工計画書サンプル集（準備工・本体工）

現場技術員が受注者から提出される施工計画書を点検・確認する際の**時短**と**記載ミスの見落とし防止**を目的としたサンプル（標準様式例）です。

## 収録ファイル

| ファイル | 内容 |
|---|---|
| `準備工_施工計画書サンプル.md` | 準備工（仮設・測量・交通処理・事前調査等）の施工計画書サンプル |
| `本体工_施工計画書サンプル.md` | 本体工（掘削・盛土・基礎・コンクリート・舗装等）の施工計画書サンプル |
| `施工計画書サンプル_準備工本体工.xlsx` | 上記2つをExcelにまとめた版。表紙・工事概要・ガントチャート形式の計画工程表・章立てごとの記載例＋📌チェックポイント（確認欄付き）・使用機械/材料一覧・品質管理/出来形管理基準・添付資料チェックリスト（添付件数を自動集計）を収録。黄色セル＝記入例、オレンジセル＝チェックポイントで色分け。 |

## 使い方（点検時短のポイント）

1. **様式の基準として使う**
   受注者ごとに章立てや記載順がバラバラだと、点検のたびに「どこに何が書いてあるか」を探すことになり時間を食います。本サンプルの章立て・見出しを受注者への**提出様式の標準（雛形）**として提示し、これに準拠させることで点検の目線を固定できます。

2. **チェックポイントを読み合わせる**
   各章に `📌チェックポイント` として、記載漏れ・数値の不整合など**受注者が間違えやすい項目**を明記しています。点検時はまずこの📌の項目だけを先に確認し、OKであれば本文を流し読みする、という2段階チェックにすると時間短縮になります。

3. **チェックリストとして印刷・転用する**
   📌の項目を抜き出してExcel等のチェックリスト化すれば、そのまま点検記録（是正指示の根拠）としても使えます。

4. **工種・現場条件に応じて調整する**
   本サンプルは道路工事等を想定した一般的な構成です。河川工事・上下水道工事等、工種が異なる現場では、本体工側の「4. 施工方法」の項目立てを実工種に置き換えてください（準備工側の構成はほぼ共通で使えます）。

## 位置付け

- 参照法令・基準：土木工事共通仕様書、土木工事施工管理基準、品質管理基準（発注者の基準に読み替えてください）
- 本サンプルはあくまで**記載項目の見本**であり、数値・工法等の記載内容はダミーです。実工事の設計図書・特記仕様書の内容に置き換えて使用してください。
