# 販売ページ用 写真の撮り方

販売ページの写真は、今ある3枚を切り抜き・色補正して使っている（`sales/photos/*-crop.jpg`）。
撮り直せば、ページの印象が大きく変わる。スマートフォンで十分。

## 優先して撮りたい写真

| 優先 | 写真 | 使う場所 |
|---|---|---|
| 1 | **ウッドデッキで家族や友人がくつろいでいる様子**（囲炉裏テーブルを囲む、BBQなど。顔は写さなくてよい） | ページのいちばん上 |
| 2 | 囲炉裏テーブルで炭火（またはカセットコンロ）を使っているところ | STEP3の紹介 |
| 3 | 教材どおりにつくった踏み台・プランター台（新しい木の色のうちに） | STEP1・STEP2の紹介 |
| 4 | 作業中の手元（さしがねで線を引く、すき間ゲージをはさむ、水平器を当てる） | 「なぜ小さな作品から」の欄 |
| 5 | 監修者が作業している姿（後ろ姿や手元でもよい） | 監修者紹介 |

## 撮り方のコツ

- **時間**：晴れた日の朝9〜10時か、夕方。真昼は影が濃く、色が白っぽくなる
- **背景**：物干し・植木鉢・道具を画面の外へ片づける。背景は空、植栽、デッキの床板だけにする
- **角度**：正面より、斜め45°・少し上から。立体感が出る（教材の立体図と同じ向き）
- **大きさ**：作品が画面の6〜7割になるまで近づく
- **向き**：横向きで撮る（ページのいちばん上は横長で使う）
- **手入れ**：囲炉裏テーブルは、ふたの塗装がはげている。撮る前に塗り直すか、ふたを外して炉の側から撮る

撮った写真は、このチャットに送ってもらえれば、切り抜き・色補正してページに入れる。
