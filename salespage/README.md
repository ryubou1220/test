# コンテンツフリーダム セールスページ

インフォトップ販売用のセールスページです。商品販売編で解説している「レター7要素」（共感 → 提案 → 商品とベネフィット → 信頼・実績 → オファー → よくある質問 → 行動を促す一言）の順で組み立てています。

## ファイル

- `index.html` … ページ本体（HTMLとCSSのみ。外部から読み込むのはGoogle Fontsだけ）
- `img/cover.jpg` … ヒーロー画像（導入編の原稿に入っていた表紙画像）

## 公開前に差し替えるところ

1. `__INFOTOP_ORDER_URL__` … インフォトップの購入リンク。ページ内のボタン4か所すべて
2. 黄色く表示される `class="todo"` の箇所
   - 価格（オファー欄と特定商取引法の表記の2か所）
   - 提供形式・サポート内容
   - 返金保証（付けない場合はブロックごと削除）
   - 特定商取引法に基づく表記（販売事業者・所在地・連絡先など）

差し替えたら `class="todo"` を外してください（黄色の表示が消えます）。

## 確認

`index.html` をブラウザで開けば、そのまま表示を確認できます。
