一つでも心当たりがあるなら、このまま読み進めてください。

実はボクも、まったく同じことを考えていました。建設現場の監督として35年。給料日の前になると残高を気にして、欲しいものを「今月は我慢しよう」と諦める。そんな生活を続けてきました。

退職が近づいたとき、「この先、収入源は年金だけなのか」と考えて、正直、怖くなりました。35年分の経験は確かに自分の中にあるのに、それをお金に変える方法を、何も知らなかったからです。

50代・60代にこそ向いている、3つの理由

REASON 01

経験そのものが商品になる

必要なのは若さや流行の知識ではなく、積み重ねてきた経験です。年齢を重ねた分だけ、語れることが増えていきます。

REASON 02

体力に頼らず、自宅でできる

在庫も店舗もいりません。仕入れがないので売れ残りの損失もなく、初期費用はパソコンとネット環境程度です。

REASON 03

自分のペースで、長く続けられる

空いた時間に少しずつ進められます。一度作った商品は繰り返し販売でき、定年のない仕事として育てていけます。

ただし、良いことばかりではありません

何もしないで収入が入る、という話ではありません。売れるまでには時間がかかりますし、中身の質や、届ける仕組みづくりも欠かせません。

このプログラムでは、そうしたデメリットも最初に正直にお伝えします。知っていれば、つまずいたときに慌てずに済むからです。

PROGRAMコンテンツフリーダム
～経済的自由への道～

コンテンツフリーダムは、コンテンツ販売を「商品を作る → 販売ページを用意する → 届ける」という流れに沿って、ゼロから順番に学べるプログラムです。

名前の「フリーダム」は、何もしなくていい生活のことではありません。やりたいことを、やりたいタイミングで選べる状態のことです。収入の柱を、自分の手で増やせる。そうした小さな「選べる」を積み重ねるための道のりを、全7回でお届けします。

このプログラムで、できるようになること

  • 長年の仕事や暮らしの中から、「売れる商品の種」を見つけられるようになる
  • 自分の経験を、“たった一人”の悩みに届く商品の形にまとめられるようになる
  • 難しい言葉を使わず、読んですぐ実践できるわかりやすい商品に仕上げられるようになる
  • 7つの要素に沿って、自分の言葉で販売ページ（レター）を書けるようになる
  • 売り込まずに、必要としている人へ商品を届ける道筋をつくれるようになる
  • 反応がない時期も焦らず、商品を育てながら続けられるようになる

カリキュラム（全7回）

  1. 予告編

    あなたが本当に欲しいものは？

    「どうありたいか」を言葉にして、ぼんやりした「いつか」を、紙に書き出せる「いつ、何を」に変えます。
    → 目指すゴールと、そこへ向かう理由がはっきりする

  2. 導入編

    情報販売とは何か、なぜ副業に合うのか

    情報販売の仕組み、副業に向いている理由、「作成 → 販売ページ → 販売」の全体の流れを押さえます。
    → コンテンツ販売の全体像がつかめる

  3. 基礎知識編

    メリット・デメリットと、売れる3大ジャンル

    商品の形式、5つのメリットと3つのデメリット、売れるジャンル、始めるために必要なもの、稼げる人と稼げない人の違いを学びます。
    → 「何を・誰に・どうやって売るか」を決められる

  4. 商品作成編

    売れる商品を作る3ステップ

    ターゲットの目線に立つ、簡単・お手軽にする、安心して取り組める約束をする。リサーチ先の一覧と、ペルソナの作り方も具体例つきで解説します。
    → “たった一人”に届く商品を形にできる

  5. 商品販売編

    販売ページ（レター）の7要素

    共感・提案・ベネフィット・信頼・オファー・よくある質問・行動を促す一言。このページ自体も、この7要素で組み立てています。
    → 自分の言葉で、筋の通ったレターが書ける

  6. 集客編

    導線の4段階で、レターを必要な人に届ける

    「出会う → 興味を持つ → 信頼する → 行動する」の順番と、まず決めるべき2点（出会う場所と販売ページ）。SNS・ブログ・メルマガ／LINEの役割分担と、無理なく続けられる発信の頻度の決め方をお伝えします。
    → 売り込まずに、商品を届ける導線をつくれる

  7. フォロー編

    始めた後の壁を越えて、長く続けるために

    「反応がない」「人と比べてしまう」「やる気が落ちる」という3つの壁と、その乗り越え方。お客さまの声やレターの反応をもとに、商品とレターを育てていく方法をお伝えします。
    → 数字が出ない時期も、焦らず積み上げ続けられる

ABOUT MEはじめまして、りゅう坊です

ボクも、あなたと同じ世代です。35年間、建設現場の監督として働いてきました。体力的にも精神的にもハードな仕事で、仕事に悩み、鬱病に近い状態を経験したこともあります。

退職を前に「この先は年金だけか」と不安になり、2018年にネットの世界へ飛び込みました。パソコンに詳しかったわけでも、文章を書く仕事をしていたわけでもありません。最初は「現場一筋の自分の経験なんて、誰の役にも立たない」と思っていました。

でも、ブログやコラムで現場のことを書いてみると、「読んでよかった」「参考になった」という声が届くようになりました。若手社員向けのコラムを依頼され、電子書籍も出版しました。

そのとき気づいたのは、自分が「当たり前」だと思っていたことが、誰かにとっては「知りたかったこと」だったという事実でした。

正直にお伝えすると、ボクは大きな実績を挙げたトップランナーではありません。でも、だからこそ、同じ年代でこれから一歩を踏み出す方の気持ちが、よくわかるつもりです。若い成功者が「簡単ですよ」と言うのと、同じように会社勤めを終えた人間が「こうやったらできましたよ」と言うのとでは、聞こえ方がまったく違うはずです。

「今さら」と思う気持ちも、よくわかります。でも、経験を積んだ今だからこそ語れることがあります。あなたと同じ目線で、一歩ずつ一緒に進んでいきたい。そう考えて、このプログラムを作りました。

FAQよくあるご質問

50代・60代から始めても、遅くありませんか？

遅くありません。コンテンツ販売で商品になるのは、あなたがこれまでに積み重ねてきた経験です。年齢を重ねているほど、語れる経験も増えます。若い人と速さを競う仕事ではないので、ご自身のペースで進められます。

パソコンやインターネットに詳しくありません。

メールの送受信や、文字の入力ができれば始められます。ボク自身も、特別な知識があったわけではありません。必要な操作は、講義の流れに沿って一つずつ覚えていけば大丈夫です。最初の情報集めや下書きは、スマホでも進められます。

文章を書くのが苦手です。

大丈夫です。うまい文章である必要はなく、伝わる文章であれば十分です。プログラムの中で、文章の組み立て方そのものをお伝えします。ボク自身も、もともと文章を書く仕事をしていたわけではありません。

本当に、自分の経験にお金を払ってくれる人がいるのでしょうか？

あなたにとっては当たり前の仕事の段取りや暮らしの知恵も、これから同じ道を歩く人にとっては「知らなかった、助かった」ことです。情報の価値は、発信する側の自己評価ではなく、受け取る側がどれだけ困っていたかで決まります。見つけ方はプログラムの中で具体的にお伝えします。

専門家でもないし、目立った実績もありません。

心配いりません。むしろ「少し先を歩いてきた人」の言葉のほうが、これから同じ道を歩く人には届きやすい傾向があります。実績がなくても、商品を作った経緯や、歩んできた道のりそのものが信頼の材料になります。

仕事の経験ではなく、趣味や家庭の経験でも商品になりますか？

もちろんです。家庭菜園や釣りなどの趣味、子育てや親の介護の経験も、立派な商品の種になります。大切なのは、あなた自身が熱量を持って語れるかどうかです。

体力や時間に、あまり自信がありません。

自宅で、座ったまま進められる仕事です。在庫を運んだり、人に会いに出かけたりする必要はありません。毎日でなくても、週に何回か、続けられるペースで進めれば十分です。

SNSをほとんど使ったことがありません。

全部を同時に始める必要はありません。まずは商品を届ける場所を一つ決めて、そこから少しずつ慣れていけば大丈夫です。集客は人数の多さではなく「順番」の話なので、少人数との関係を丁寧に積み上げることから始められます。

どのくらいで収入になりますか？

正直にお伝えすると、売れるまでには時間がかかります。始めた初日に売れることはほとんどありませんし、成果には個人差があります。このプログラムは、焦らず一歩ずつ積み上げていくための道筋をお伝えするものです。最終回の「フォロー編」では、数字が出ない時期にどう続けるか、商品とレターをどう直していくかも具体的にお伝えしています。

ここから、始めてみませんか？

「今さら新しいことなんて」と思う気持ちは、ボクにもよくわかります。ボク自身も、「いつか何かやろう」と何年も先延ばしにしていた一人でした。

でも、最初に作ったコンテンツは、今見返すと恥ずかしいくらい簡素なものでした。それでも「出してみた」からこそ、読者の反応が返ってきて、次に何をすればいいかが見えてきたのです。

あなたがこれまで積み重ねてきた30年、40年は、それだけで誰かの役に立つ財産です。完璧でなくて大丈夫です。もし今、「これなら書けるかも」というテーマが一つでも浮かんだなら、それがあなたの最初の一歩です。

そのテーマを、一緒に商品にしていきましょう。
