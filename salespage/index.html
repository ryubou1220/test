あなたの経験と知識で、新しい収入の柱をつくる方法。

それが「コンテンツ販売」です。

コンテンツ販売とは、あなたの経験や知識を、PDF・動画・音声・テンプレートなどのデジタル商品にまとめて、オンラインで販売するビジネスです。

「毎日の献立に悩む人のための時短レシピ」も、「スマホで子どもの写真をきれいに撮るコツ」も、立派な商品になります。専門家である必要はありません。人より一歩だけ詳しい分野があれば、それが商品の種です。

本業を持つ人の副業に向いている、3つの理由

REASON 01

初期費用がほとんどかからない

必要なのはパソコンとネット環境程度。自分のサイトを持つ場合も、ドメインやサーバー代で年間1万円ほどです。

REASON 02

在庫を抱えない

仕入れがないので、売れ残りの損失がありません。うまくいかなくても、失うのは制作にかけた時間くらいです。

REASON 03

自分のペースで進められる

時間や場所に縛られず、本業のスキマ時間で少しずつ積み上げられます。一度作った商品は、繰り返し販売できます。

ただし、良いことばかりではありません

クリックひとつで何万円、何もしないで収入が入る、という話ではありません。売れるまでには時間がかかりますし、中身の質や、届ける仕組みづくりも欠かせません。

このプログラムでは、そうしたデメリットも最初に正直にお伝えします。知っていれば、つまずいたときに慌てずに済むからです。

PROGRAMコンテンツフリーダム
～経済的自由への道～

コンテンツフリーダムは、コンテンツ販売を「商品を作る → 販売ページを用意する → 届ける」という流れに沿って、ゼロから順番に学べるプログラムです。

名前の「フリーダム」は、何もしなくていい生活のことではありません。やりたいことを、やりたいタイミングで選べる状態のことです。収入の柱を、自分の手で増やせる。そうした小さな「選べる」を積み重ねるための道のりを、全7回でお届けします。

このプログラムで、できるようになること

  • 自分の経験や趣味の中から、「売れる商品の種」を見つけられるようになる
  • リサーチをもとに“たった一人”のお客さま像（ペルソナ）を描き、その人に届く商品を形にできるようになる
  • 難しい言葉に頼らず、「すぐ実践できる」わかりやすい商品にまとめられるようになる
  • 7つの要素に沿って、自分の言葉で販売ページ（レター）を書けるようになる
  • 商品作成から販売までの一連の流れを、自分の手で回せるようになる

カリキュラム（全7回）

  1. 予告編

    あなたが本当に欲しいものは？

    「どうありたいか」を言葉にして、ぼんやりした「いつか」を、紙に書き出せる「いつ、何を」に変えます。
    → 目指すゴールと、そこへ向かう理由がはっきりする

  2. 導入編

    情報販売とは何か、なぜ副業に合うのか

    情報販売の仕組み、副業に向いている理由、「作成 → 販売ページ → 販売」の全体の流れを押さえます。
    → コンテンツ販売の全体像がつかめる

  3. 基礎知識編

    メリット・デメリットと、売れる3大ジャンル

    商品の形式、5つのメリットと3つのデメリット、売れるジャンル、始めるために必要なもの、稼げる人と稼げない人の違いを学びます。
    → 「何を・誰に・どうやって売るか」を決められる

  4. 商品作成編

    売れる商品を作る3ステップ

    ターゲットの目線に立つ、簡単・お手軽にする、安心して取り組める約束をする。リサーチ先の一覧と、ペルソナの作り方も具体例つきで解説します。
    → “たった一人”に届く商品を形にできる

  5. 商品販売編

    販売ページ（レター）の7要素

    共感・提案・ベネフィット・信頼・オファー・よくある質問・行動を促す一言。このページ自体も、この7要素で組み立てています。
    → 自分の言葉で、筋の通ったレターが書ける

  6. 集客編

    レターを必要な人に届ける

    SNS・ブログ・メルマガの使い分けと、無理なく続けられる集客の考え方をお伝えします。
    → 商品を届ける導線をつくれる

  7. フォロー編

    販売を始めた後、長く続けるために

    商品を「作って終わり」にせず、お客さまの声をもとに育て続けていくための考え方を整理します。
    → 一度きりで終わらない、積み上げ型のビジネスになる

FAQよくあるご質問

文章を書くのが苦手でも大丈夫ですか？

大丈夫です。うまい文章である必要はなく、伝わる文章であれば十分です。プログラムの中で、文章の組み立て方そのものをお伝えします。ボク自身も、もともと文章を書く仕事をしていたわけではありません。

パソコンに詳しくなくてもできますか？

できます。特別な専門知識は必要ありません。必要な操作は、一つずつ順番に覚えていけば問題ありません。最初の情報収集や下書きは、スマホだけでも進められます。

本業が忙しくて、時間が取れないのですが？

コンテンツ販売は、時間のない人にこそ向いているビジネスです。隙間時間を使って少しずつ積み上げていく前提でお伝えしているので、まとまった時間が取れなくても進められます。

本当に、自分の経験にお金を払ってくれる人がいるのでしょうか？

あなたにとって当たり前のことは、別の誰かにとっては「知らなかった、助かった」ことです。情報の価値は、発信する側の自己評価ではなく、受け取る側がどれだけ困っていたかで決まります。見つけ方はプログラムの中で具体的にお伝えします。

専門家でもないし、実績もありません。

心配いりません。むしろ「少し前まで初心者だった人」の言葉のほうが、同じ初心者には届きやすい傾向があります。実績がなくても、商品を作った経緯や考えてきた過程そのものが、信頼の材料になります。

同じジャンルの商品がすでにたくさんあったら、売れませんか？

同じジャンルでも、あなたの経験や言葉で語られた情報は、ほかの誰にも作れないオリジナルになります。競合がいるジャンルは、需要がある証拠でもあります。

今の仕事とまったく関係のないジャンルでも始められますか？

もちろんです。趣味やプライベートで培ってきた経験も、立派な商品の種になります。大切なのは、あなた自身が熱量を持って語れるかどうかです。

どのくらいで収入になりますか？

正直にお伝えすると、売れるまでには時間がかかります。始めた初日に売れることはほとんどありませんし、成果には個人差があります。このプログラムは、焦らず一歩ずつ積み上げていくための道筋をお伝えするものです。

ここから、始めてみませんか？

人は、思っているだけで行動に移せないことが普通です。ボク自身も、「いつか何かやろう」と何年も先延ばしにしていた一人でした。

でも、最初に作ったコンテンツは、今見返すと恥ずかしいくらい簡素なものでした。それでも「出してみた」からこそ、読者の反応が返ってきて、次に何をすればいいかが見えてきたのです。

完璧でなくて大丈夫です。もし今、頭の中に「これなら書けるかも」というテーマが一つでも浮かんだなら、それがあなたの最初の一歩です。

そのテーマを、一緒に商品にしていきましょう。
