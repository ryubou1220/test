# 三日会 チーム共有ページ セットアップ手順

メンバーは **リンクを開くだけ** で使えます（Claude や Google のアカウントは不要）。

データは、あなたの Google ドライブにあるスプレッドシート **「三日会 共有データ」** に保存されます（作成済み・リンクを知っている人は誰でも閲覧・編集できる設定済み）。
https://docs.google.com/spreadsheets/d/1uMDPTE9VTumjFtwZQqFI311PAjMIhQBXlZ9885yfxD8/edit

このスプレッドシートは、下の設定をしなくても **今すぐ** リンクを送ればメンバーが直接書き込めます。
下の設定をすると、スマホで使いやすい専用ページ（出欠ボタンつき）からも同じデータを読み書きできるようになります。

最初に1回だけ、パソコンで次の作業をしてください（10分ほど）。Google アカウントが必要なのは、この作業をするあなただけです。

---

## 1. Apps Script のプロジェクトを作る

1. パソコンのブラウザで **https://script.google.com** を開き、Google アカウントでログインします。
2. 左上の **「新しいプロジェクト」** を押します。
3. 左上の「無題のプロジェクト」を押して、名前を **「三日会 共有ページ」** に変えます。

## 2. プログラムを貼り付ける（2つ）

**① コード.gs**

1. 画面に最初から出ている `function myFunction() { ... }` を **全部消します**。
2. このフォルダの **`Code.gs`** の中身を全部コピーして、貼り付けます。
3. 合言葉を使う場合は、上のほうにある
   `const PASSWORD = '';`
   の `''` の間に合言葉を入れます（例：`const PASSWORD = 'mikka2026';`）。
   空のままだと合言葉なしで、リンクを知っている人は誰でも見て書き込めます。

**② index.html**

1. 左側の「ファイル」の横の **「＋」** → **「HTML」** を押します。
2. 名前を **`index`** と入力します（「.html」は自動で付きます）。
3. 最初から入っている内容を全部消して、このフォルダの **`index.html`** の中身を全部貼り付けます。

最後に、上の **保存ボタン（💾）** を押します。

## 3. 公開する（デプロイ）

1. 右上の青い **「デプロイ」** → **「新しいデプロイ」** を押します。
2. 「種類の選択」の歯車マーク → **「ウェブアプリ」** を選びます。
3. 次のように設定します。
   - 説明：（空でOK）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **「デプロイ」** を押します。
5. 「アクセスを承認」→ 自分のアカウントを選びます。
   「このアプリは Google で確認されていません」と出たら、**「詳細」** → **「三日会 共有ページ（安全ではないページ）に移動」** → **「許可」** を押します。
   （自分で作ったプログラムなので問題ありません。スプレッドシートを作って読み書きする許可です。）
6. **「ウェブアプリ」の URL**（`https://script.google.com/macros/s/.../exec`）が表示されます。これが共有ページのリンクです。

## 4. メンバーに共有する

- URL を LINE などでメンバーに送ってください。開くだけで使えます。
- スマホのホーム画面に追加しておくと便利です。
- 専用ページで書き込んだ内容は「三日会 共有データ」に入ります。スプレッドシートで直接書き足した行も、専用ページに表示されます。

## よくある質問

**ページの上に「このアプリケーションは Google ではなく、別のユーザーによって作成されたものです」と出る**
Google のウェブアプリには必ず表示されるお知らせです。そのまま使えます。

**合言葉を変えたい / プログラムを更新したい**
`Code.gs`（または `index.html`）を書き換えて保存したあと、
**「デプロイ」→「デプロイを管理」→ 鉛筆マーク（編集）→ バージョン「新バージョン」→「デプロイ」** を押します。
URL は変わりません。（「新しいデプロイ」を押すと URL が変わってしまうので注意）

**ほかの人の書き込みはいつ反映される？**
画面を開いている間、30秒ごとに自動で最新になります。右下の「最新にする」ですぐに更新することもできます。

**注意**
リンク（と合言葉）を知っている人は誰でも書き込めます。住所や電話番号などの個人情報は書かないようにしてください。
