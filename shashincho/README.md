# 写真帳 貼り付けツール

業務報告書（写真帳）Excel の写真枠に、新しく撮った写真を前回と同じアングルの枠へ貼り付ける。

## 前提となるテンプレートの形
- 写真枠は「・」（B列／W列）＋キャプション（C列／X列）の行の下 10 行。
- 前回の写真は印刷範囲（A〜AQ）の右側、AR〜BB列に並べておく（左枠の見本は AR、右枠の見本は AW）。
  見本が無い枠は、枠内に貼ってある写真を見本として扱う。
- 同じ確認箇所（J11）で同じ見本画像を使っている枠は「同じアングル」とみなし、1 枚の写真を全部に貼る
  （例：定期観測(久僧) と 久僧(浸食部)／(堆積部) シート）。

## 使い方
```
pip install -r requirements.txt

# 1) 撮影リスト（CSV）を作る
python shashincho.py checklist 写真帳.xlsx --out-csv 撮影リスト.csv

# 2) 写真を貼る
python shashincho.py paste 写真帳.xlsx 写真/ -o 写真帳_完成.xlsx --report 貼付結果.html
```
写真フォルダは現場ごとのサブフォルダに分ける（フォルダ名がシート名に含まれる語：`川上谷川` `成願寺川` `久僧` `宇川` `木津`）。

- シート名に「定期観測」を含む現場：見本と画像照合（SIFT＋射影変換の一致点数）して割り当てる。順番は自由、予備カットが混ざってもよい。
- それ以外（工事の立会写真など）：撮影時刻順に、撮影リストの番号順で貼る。
- 一致度が `--min-score`（既定 25）未満の枠は貼らずに報告する。
- `貼付結果.html` で見本と今回写真を並べて確認できる。間違いは `貼付結果.csv` の「写真ファイル」列を直し、
  `--map 貼付結果.csv` を付けて再実行すると、その割り当てどおりに貼る。
- `--drop-ref` を付けると右側の見本写真を削除する（ファイルが軽くなる）。付けなければ残すので、次回の見本に使える。

xlsx は ZIP 内の XML を直接編集するので、矢印・丸・番号ラベルなどの図形や書式はそのまま残る。
写真は長辺 1024px の JPEG に縮小して貼る。

## 印刷用の撮影アングル帳
```
python checklist_pdf.py 写真帳.xlsx 撮影アングル帳.pdf
```
A4 縦に 6 枚ずつ、番号・キャプション・貼付先・撮影済チェック欄付きで出力する（現場ごとに改ページ）。
