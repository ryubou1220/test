## 塗り直しの目安

| 場所 | 目安 | 次の予定 |
|---|---|---|
| 天板の上面・側面・木口 | **最低2年ごと** | 　　　　年　　月ごろ |
| 天板の下面・根太・根がらみ | **最低5年ごと** | 　　　　年　　月ごろ |
| 日や手がよく当たる所（踏み台のまわり、手すりなど） | **1〜2年で早めに** | 　　　　年　　月ごろ |

スマートフォンのカレンダーに、次の予定を入れておくと忘れません。

## 塗り直しのしかた

1. **天気を選ぶ。** 晴れが1〜2日続いたあとの、晴れた日に塗ります。木が湿っていると、塗料が染み込みません。
2. **掃除する。** ほこりを掃き、汚れはデッキブラシで水洗いします。目地の水あかは、細いブラシで落とします。よく乾かします。
3. **塗る。** 塗料はよくかき混ぜます。目地のような塗りにくい所から塗り、目立つ所は最後に。木目に沿って、薄く塗ります。木口（切り口）は塗料をよく吸うので、多めに塗ります。
4. **2回目を塗る。** 1回目がよく乾いてから、もう一度塗ります。

> 前と同じ塗料を使うと、色むらが出にくくなります。上の「わが家のウッドデッキ」に、塗料の名前と色を書いておいてください。

## 点検のポイント

### いちばん大事なのは「目地」

雨水は目地（板と板のすき間）を伝って下へ流れます。そのため、**天板の側面と根太の上面が、いちばん長く湿ったまま**になります。ここが傷みやすい場所です。

### もうひとつの弱点は「根太と支柱を留めるビス」

サンドイッチ工法では、支柱を根太で両側から挟んでビスで留めています。デッキの寿命は、このビスで決まります。

### 点検チェックリスト

| いつ | 見る所 | チェック |
|---|---|---|
| ふだん | ほこりや落ち葉がたまっていない | □ |
| ふだん | 汚れは、デッキブラシで水洗い | □ |
| 季節ごと | 目地に、水あかや土がつまっていない | □ |
| 季節ごと | 天板に、ささくれ・割れ・反りがない | □ |
| 季節ごと | ビスの頭が浮いていない（浮いていたら締め直す） | □ |
| 年に1回 | 天板の色があせて、水をはじかなくなっていない | □ |
| 年に1回 | 床下をのぞいて、根太と支柱を留めるビスにさびや緩みがない | □ |
| 年に1回 | 支柱の根元や束石のまわりに、水がたまっていない | □ |
| 年に1回 | 歩いて、きしみ・たわみ・ぐらつきがない | □ |

> **水をはじくかの確かめ方：** 天板に水を少したらしてみます。玉になって転がれば、まだ大丈夫。すぐに染み込んで色が濃くなるなら、塗り直しの時期です。

## こんなときは

| 気づいたこと | すること |
|---|---|
| ビスの頭が浮いている | 締め直す。木がやせて効かないときは、少しずらして新しいビスを打つ |
| 天板の一部が割れた・腐った | その1枚だけ外して、同じ寸法の板に取り替える。取り替えた板は、先に塗っておく |
| ささくれがある | サンドペーパーで削って、その部分を塗り直す |
| 床下のビスがさびている | 早めにステンレスのビスに打ち替える。デッキの寿命にかかわる |
| ぐらつく・たわむ | 写真を撮って、ご相談ください |
