道具は、一度に全部そろえなくて大丈夫です。作品ごとに、必要なものを少しずつ足していきます。高い道具は借りる、一度しか使わない作業は頼む、ちょっとした道具は端材で作る。この帳面は、そのための手引きです。

## 1. そろえる順番表

作品ごとに「ここで初めて必要になる道具」だけを並べました。前の作品の道具は、そのまま使い続けます。

| 作品 | 新しく必要になる道具 |
|---|---|
| STEP1 踏み台 | さしがね、メジャー、鉛筆、ノコギリ、インパクトドライバー、3mmのドリルビット、保護メガネ、手袋 |
| STEP2 プランター台 | まっすぐな長い定規、すき間ゲージ（自作） |
| STEP3 囲炉裏テーブル | 水平器（30cm以上）、カッターと金属の定規、防じんマスク |
| STEP4 木製門扉 | スコップ、穴掘り器、練り舟とクワ、水糸と杭、突き棒（自作） |
| ウッドデッキ | 電動丸ノコ、チョークライン、クランプ、タンパー（自作）、直角定規（自作）、受け台（自作） |

> 電動工具は、DIY用で十分です。プロ用は重く、値段も高くなります。

## 2. 買う・借りる・頼む・作る

| 方法 | 向いている道具・作業 | ポイント |
|---|---|---|
| **買う** | さしがね、メジャー、ノコギリ、インパクトドライバー、水平器 | どの作品でも使う。長く使うものから買う |
| **借りる** | 穴掘り器、電動丸ノコ（デッキまで買わない場合） | ホームセンターの工具レンタルを使う。買う前に店で聞いてみる |
| **頼む** | 木材のカット、長い材料の運搬 | カットサービス（1カット数十円ほど）、軽トラックの貸し出し |
| **作る** | すき間ゲージ、タンパー、直角定規、受け台 | 作品の余りの木で作れる（次の章） |

## 3. 端材でつくる治具

治具（じぐ）は、同じ作業を正確にくり返すための手作りの道具です。どれも作品の余りの木で作れます。寸法は目安です。手元の材料に合わせてください。

## 4. 道具の使い方のコツ

### さしがね

- 短い方を材料の側面にぴったり当て、長い方に沿って線を引く
- 上の面に引いたら、側面にも線を回す。切るときの目安になる
- 鉛筆は削って、細い線で。赤い鉛筆は木の上で見やすい

### 水平器

- 気泡が、2本の線のちょうど真ん中にあれば水平（垂直）
- 柱の垂直は、となり合う2つの面に当てて見る。1つの面だけでは、もう一方に傾いていても分からない
- 当てる向きを左右反対にしても気泡が同じ位置なら、その水平器は正確

### インパクトドライバー

- ビスの頭に合ったビット（コーススレッドなら多くは＋2番）を使う
- 本体をビスとまっすぐに構え、しっかり押しつけながら回す。押しが弱いと、ビスの頭の溝がつぶれる
- 打ち始めはゆっくり。ビスが立ってから力を入れる
- 天板のビスは、頭が面から1〜2mm沈んだところで止める

### のこぎり

- 日本のノコギリは、引くときに切れる。押すときは力を抜く
- 切り始めは、親指の爪を刃の横に当てて位置を決め、軽く数回引いて溝をつくる
- 刃の長さ全体を使って、ゆっくり大きく引く

### 電動丸ノコ

- 刃の出は、材料の厚みより少し出るくらいに合わせる
- 丸ノコの真後ろに立たない。斜め後ろに立つ
- 切り落とす側が下に落ちる位置に台を置く。刃がはさまると、手前に跳ね返る（キックバック）
- 刃の交換や、角度・深さを変えるときは、必ず電源を抜く
- 保護メガネを必ずかける。刃が止まるまで手を離さない
