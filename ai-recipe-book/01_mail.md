# 第1章　メール・チャットを3分で片づける10のレシピ

メールは、1通ごとの時間は短くても、1日全体では大きく時間を取られる仕事です。
気づけば午前中がメールの返信だけで終わっていた、という経験がある人も多いのではないでしょうか。

しかも時間がかかるのは、書くことそのものより「どう書けば角が立たないか」と悩む時間です。
AIはこの「悩む時間」を肩代わりするのがとても得意です。

この章では、仕事でよく出てくる10の場面について、コピペで使える指示文を紹介します。
〔　〕の部分を自分の状況に書き換えて、AIに貼り付けるだけで使えます。

> **この章のコツ**
> AIが出した文章は「80点の下書き」です。最後に自分の言葉で1〜2か所直してから送りましょう。それだけで「AIっぽさ」が消えます。

---

## レシピ01｜角を立てずに断るメール

**⏱ 15分 → 2分**

**こんな時：** 取引先から無理な納期や値下げを頼まれた

```
あなたはビジネスメールの専門家です。
以下の依頼を、関係を悪くせずに丁寧に断るメールを書いてください。

・相手：〔例：取引先の担当者〕
・依頼内容：〔例：来週金曜までの納品〕
・断る理由：〔例：製造ラインが埋まっている〕
・代わりに提案できること：〔例：再来週水曜なら可能〕

条件：300字以内／件名も作成／最後に今後も関係を続けたいと伝わる一文を入れる
```

**出力例（抜粋）**

> ご希望の来週金曜日の納品について検討いたしましたが、現在製造ラインが埋まっており、品質を保ったままお届けすることが難しい状況です。
> 代わりに、再来週水曜日でしたら確実に納品が可能です。

**ポイント：** 「代わりに提案できること」を入れると、ただの断りが「代わりの案を出すメール」に変わります。

---

## レシピ02｜誠意が伝わるお詫びメール

**⏱ 20分 → 3分**

**こんな時：** 納品ミスや請求書の誤りなどをしてしまった

```
あなたは信頼回復のプロです。
以下のミスについて、誠意が伝わるお詫びメールを書いてください。

・相手：〔例：取引先の部長〕
・起きたこと：〔例：請求書の金額を間違えて送った〕
・原因：〔例：手入力の確認漏れ〕
・対応：〔例：正しい請求書を本日中に再送する〕
・再発防止策：〔例：送付前に2名でチェックする〕

条件：言い訳がましくしない／「お詫び→経緯→対応→再発防止→再度のお詫び」の順／件名も作成
```

**出力例（抜粋）**

> 先日お送りしたご請求書に金額の誤りがございました。誠に申し訳ございません。
> 原因は、私の手入力による確認漏れです。正しいご請求書は、本日中に改めてお送りいたします。

**ポイント：** お詫びメールは「順番」が命です。順番を指定すれば、AIが型どおりに整えてくれます。

**応用：** 相手が怒っているときは「相手はかなり怒っている」と書き足すと、より丁寧になります。

---

## レシピ03｜嫌味にならない催促メール

**⏱ 10分 → 1分**

**こんな時：** 頼んだ資料や返事が、期限を過ぎても来ない

```
以下の件について、相手を責めずに、でも確実に動いてもらえる催促メールを書いてください。

・相手：〔例：取引先の担当者〕
・お願いしていたこと：〔例：見積書の提出〕
・新しい期限：〔例：10月17日（金）〕
・急いでほしい理由：〔例：社内の決裁に間に合わせるため〕

条件：200字以内／件名も作成
```

**出力例（抜粋）**

> 先日お願いしておりましたお見積書について、その後のご状況はいかがでしょうか。
> 社内の決裁に間に合わせるため、恐れ入りますが10月17日（金）までにご提出いただけますと大変助かります。

**ポイント：** 「急いでほしい理由」を書くと、相手は自然に「急がないと」と感じてくれます。

**応用：** 3回目の催促なら「少しだけ強めに。ただし失礼にならないように」と書き足しましょう。

---

## レシピ04｜長文メールを要約して、返信案まで作る

**⏱ 20分 → 3分**

**こんな時：** 長いメールが届いて、何を求められているのか分からない

```
以下のメールを読んで、次の3つを出してください。

1. 3行要約
2. 私が対応すべきこと（期限があれば期限も）
3. 返信の下書き（〔了承する／質問する／断る〕方向で）

〔ここにメール本文を貼る〕
```

**出力例（抜粋）**

> **対応すべきこと**
> - 出展者リストの再提出（期限：10月20日）
> - 搬入スタッフへの時間変更の連絡

**ポイント：** 「要約→やること→返信案」をまとめて頼めば、読む・考える・書くが1回で終わります。

**注意：** 社外秘の内容は、会社が使用を認めているAIだけで扱ってください。

---

## レシピ05｜送る前の「失礼チェック」

**⏱ 5分 → 30秒**

**こんな時：** 目上の人に送る前に、敬語が正しいか不安

```
以下のメールを、送る前にチェックしてください。

・相手：〔例：取引先の役員〕
・チェック項目：敬語の誤り／失礼・冷たく見える表現／誤字脱字

問題のある箇所は「元の文 → 修正案 → 理由」の形で示し、最後に修正後の全文を出してください。

〔ここにメール本文を貼る〕
```

**出力例（抜粋）**

> - 「了解しました」→「承知いたしました」
>   理由：「了解」は目上の人には失礼と受け取られることがあります。

**ポイント：** 「理由」も出してもらうと、自分の敬語のクセが分かり、同じ間違いが減っていきます。

---

## レシピ06｜英文メールを「自然な英語」で書く

**⏱ 30分 → 3分**

**こんな時：** 海外の取引先に英語でメールを送りたい

```
以下の内容を、ネイティブのビジネスパーソンが書くような自然な英文メールにしてください。

・相手：〔例：アメリカの取引先の担当者〕
・伝えたいこと：〔日本語で箇条書き〕
・トーン：〔丁寧／ややカジュアル〕

条件：件名も作成／英文の下に日本語訳をつける
```

**出力例（抜粋）**

> I wanted to let you know that the shipment will arrive on October 24 instead of October 22, due to a delay at the port.
> （港での遅延により、出荷が22日ではなく24日の到着となることをお知らせします。）

**ポイント：** 日本語訳をつけてもらえば、意図どおりの英文かを送る前に確認できます。

**応用：** 届いた英文メールを貼って「日本語に訳して、返信案も英語で」と頼めば、受信から返信までまとめて終わります。

---

## レシピ07｜商談・訪問後のお礼メール

**⏱ 10分 → 1分**

**こんな時：** 商談の後、その日のうちにお礼を送りたい

```
今日の商談のお礼メールを書いてください。

・相手：〔例：〇〇株式会社の山田課長〕
・商談の内容：〔例：勤怠管理システムの提案〕
・相手が特に関心を持っていたこと：〔例：スマホでの打刻〕
・次のアクション：〔例：来週中に見積書を送る〕

条件：今日の話の具体的な内容に1つ触れる／250字以内／件名も作成
```

**出力例（抜粋）**

> 特に、スマートフォンでの打刻についてご関心をお寄せいただき、大変うれしく思っております。
> お見積書は来週中にお送りいたします。

**ポイント：** 「相手が関心を持っていたこと」を入れるだけで、定型文ではない「あなたのためのお礼」になります。

---

## レシピ08｜日程調整メールを一発で決める

**⏱ 10分 → 1分**

**こんな時：** 日程調整で、何往復もやり取りしてしまう

```
打ち合わせの日程調整メールを書いてください。

・相手：〔例：取引先の担当者〕
・目的と所要時間：〔例：新商品の仕様確認、1時間、オンライン〕
・候補日時：〔例：10/21(火)14時、10/22(水)10時、10/23(木)16時〕

条件：候補日は箇条書き／どれも合わない場合の聞き方も入れる／1回の返信で決まるように工夫する
```

**出力例（抜粋）**

> - 10月21日（火）14:00〜15:00
> - 10月22日（水）10:00〜11:00
> - 10月23日（木）16:00〜17:00
>
> いずれも難しい場合は、ご都合のよい日時を2〜3つお知らせいただけましたら、こちらで調整いたします。

**ポイント：** 「1回の返信で決まるように」と指示すると、AIが「どれも合わない場合」まで先回りしてくれます。

---

## レシピ09｜上司・他部署への「通る」依頼チャット

**⏱ 10分 → 1分**

**こんな時：** 他部署に協力をお願いしたいが、面倒がられたくない

```
社内チャットで送る依頼文を書いてください。

・相手：〔例：経理部の課長。普段あまり話さない〕
・お願いしたいこと：〔例：昨年度の部署別経費データの共有〕
・理由と期限：〔例：来期予算の資料作成のため、10/24（金）まで〕
・相手の手間を減らす工夫：〔例：Excelのままで大丈夫〕

条件：5行以内／お願いを最初に書く／相手が「はい」と返すだけで済むようにする
```

**出力例（抜粋）**

> 来期予算の資料作成のため、昨年度の部署別経費データを共有いただけないでしょうか。
> 10/24（金）までにいただけると助かります。形式はExcelのままで大丈夫です。

**ポイント：** チャットは「結論が最初」が鉄則です。相手の手間を減らす一言で、引き受けてもらいやすくなります。

---

## レシピ10｜走り書きメモを「報告メール」に変える

**⏱ 20分 → 2分**

**こんな時：** 商談後のメモを、上司への報告メールにまとめたい

```
以下の走り書きメモを、上司への報告メールに整えてください。

形式：1. 結論（1〜2行） 2. 詳細（箇条書き） 3. 次のアクション 4. 相談したいこと

メモ：
〔例：〇〇社 山田課長 15時〜／予算は年内確定 300万くらい／
競合A社も提案中 価格勝負になりそう／来週見積もり 値引きどこまでOK？〕
```

**出力例（抜粋）**

> **■ 結論** 受注の見込みは十分にありますが、競合A社との価格競争になる可能性が高い状況です。
> **■ ご相談** 値引きはどの程度まで可能か、ご判断をいただけますでしょうか。

**ポイント：** メモは単語の羅列で大丈夫です。「形式」を指定すれば、上司が知りたい「結論」と「相談」が分かれて、返事も早くなります。

**応用：** 1週間分のメモを貼って「週報にして」と頼めば、週報も数分で書けます。

---

## 第1章のまとめ

| レシピ | 場面 | 時短の目安 |
|---|---|---|
| 01 | 断りメール | 15分 → 2分 |
| 02 | お詫びメール | 20分 → 3分 |
| 03 | 催促メール | 10分 → 1分 |
| 04 | 長文メールの要約と返信 | 20分 → 3分 |
| 05 | 送る前の失礼チェック | 5分 → 30秒 |
| 06 | 英文メール | 30分 → 3分 |
| 07 | 商談後のお礼メール | 10分 → 1分 |
| 08 | 日程調整メール | 10分 → 1分 |
| 09 | 社内チャットの依頼文 | 10分 → 1分 |
| 10 | メモから報告メール | 20分 → 2分 |

10のレシピに共通するのは、**「状況」と「条件」を具体的に伝えること**です。
まずは明日、1通だけでいいので試してみてください。
