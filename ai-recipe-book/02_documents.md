# 第2章　資料・文書作成を半分の時間で終わらせる10のレシピ

企画書、報告書、マニュアル。資料づくりで一番つらいのは「白紙の状態から書き始めること」ではないでしょうか。

AIを使えば、白紙から始める必要はなくなります。
まずAIに「たたき台」を作ってもらい、あなたはそれを直すだけ。
ゼロから書くより、直すほうがずっと速くて楽です。

> **この章のコツ**
> 資料づくりでは、いきなり完成品を頼まず「骨組み → 中身 → 仕上げ」と段階を分けて頼むと、思いどおりの資料になりやすくなります。

---

## レシピ11｜企画書の骨組みを10分で作る

**⏱ 60分 → 10分**

**こんな時：** 企画書を書かなければいけないが、何から書けばいいか分からない

```
あなたは企画書づくりのプロです。
以下のテーマで、企画書の骨組み（見出しと、各見出しに書くべき内容）を作ってください。

・テーマ：〔例：社内の紙の申請書を電子化する〕
・読む人：〔例：部長会議のメンバー〕
・一番伝えたいこと：〔例：年間200時間の作業が減る〕

条件：見出しは5〜7個／各見出しに「何を書くか」を1〜2行で添える
```

**出力例（抜粋）**

> 1. 現状の課題：紙の申請で、承認まで平均5日かかっている
> 2. 提案内容：申請をすべて電子化する
> 3. 効果：年間200時間の作業削減（数字の根拠も添える）

**ポイント：** 「読む人」を書くと、その人が知りたい順番で骨組みを組んでくれます。

**応用：** 骨組みができたら「3の見出しの本文を書いて」と1つずつ頼むと、質が上がります。

---

## レシピ12｜月次報告・出張報告をすぐ書く

**⏱ 30分 → 5分**

**こんな時：** 毎月の報告書や、出張後の報告書を書くのが面倒

```
以下のメモをもとに、〔月次報告書／出張報告書〕を作ってください。

形式：1. 概要（3行） 2. 実績・成果 3. 課題 4. 来月（今後）の対応

メモ：
〔例：10月売上 目標比95% 新規3件／B社の大口が来月にずれた／
展示会の反応よい 名刺80枚／来月はフォロー優先〕
```

**出力例（抜粋）**

> **1. 概要** 10月の売上は目標比95%と、わずかに未達となりました。主な原因はB社の大口案件が11月にずれたことです。一方、展示会では80名と名刺交換でき、来月以降の見込み客を確保しました。

**ポイント：** 未達の報告も、AIに頼めば「原因」と「次の手」がセットになり、前向きな報告書になります。

---

## レシピ13｜お客様向けの「お知らせ文」

**⏱ 40分 → 5分**

**こんな時：** 値上げやサービス変更を、お客様に角を立てずに伝えたい

```
お客様向けのお知らせ文を書いてください。

・内容：〔例：来年1月からの価格改定（約8%の値上げ）〕
・理由：〔例：原材料費と物流費の上昇〕
・お客様への配慮：〔例：12月末までの注文は旧価格で受ける〕

条件：お詫びと感謝を入れる／言い訳が長くならないようにする／400字以内
```

**出力例（抜粋）**

> 原材料費および物流費の高騰が続いており、企業努力だけでは価格を維持することが難しい状況となりました。
> なお、12月末日までにいただいたご注文は、現行価格にて承ります。

**ポイント：** 「お客様への配慮」を入れると、値上げのお知らせでも誠実な印象になります。

---

## レシピ14｜作業手順書（マニュアル）を作る

**⏱ 90分 → 15分**

**こんな時：** 自分しかできない仕事を、人に引き継ぎたい

```
以下の作業メモをもとに、初めての人でも迷わない手順書を作ってください。

・作業名：〔例：毎月の請求書発行〕
・読む人：〔例：入社1年目の社員〕

条件：手順は番号つき／1手順に1つの動作／間違えやすい所に「注意」をつける

作業メモ：
〔思いつくまま、やっていることを書き出す〕
```

**出力例（抜粋）**

> 3. 会計システムの「請求」タブを開く
> 4. 対象月を選び、「一括作成」を押す
> 　**注意：** 前月に締め忘れがあると、金額がずれます。先に締め処理の完了を確認してください。

**ポイント：** 作業メモは順番がバラバラでも大丈夫です。AIが手順を整理してくれます。

**応用：** 完成後に「この手順書で、初心者がつまずきそうな所はどこ？」と聞くと、抜け漏れが見つかります。

---

## レシピ15｜資料の「ツッコミどころ」を先に見つける

**⏱ 30分 → 5分**

**こんな時：** 会議で企画書を出す前に、突っ込まれそうな所を知っておきたい

```
あなたは厳しい役員です。以下の企画書を読んで、会議で突っ込みたくなる点を5つ挙げてください。

それぞれ「指摘 → なぜ気になるか → どう直せばよいか」の形で答えてください。

〔ここに企画書の本文を貼る〕
```

**出力例（抜粋）**

> - 指摘：「年間200時間削減」の根拠が書かれていない
> - なぜ気になるか：数字の出どころが分からないと、判断できない
> - 直し方：「1件あたり10分×月100件×12か月」のように計算式を添える

**ポイント：** AIに「厳しい役員」の役を与えるのがコツです。自分では気づきにくい弱点を、会議の前につぶせます。

---

## レシピ16｜長い文章を短く、読みやすくする

**⏱ 20分 → 2分**

**こんな時：** 書いた文章が長くて、何が言いたいのか伝わりにくい

```
以下の文章を、意味を変えずに読みやすく書き直してください。

条件：
・全体を〔半分〕くらいの長さにする
・1文は40字以内を目安にする
・結論を最初に書く

〔ここに文章を貼る〕
```

**出力例（抜粋）**

> （修正前）今回の件につきましては、関係各所と調整を進めてまいりましたところ、一定の方向性が見えてきたこともあり……
> （修正後）関係部署と調整した結果、方向性が決まりました。

**ポイント：** 「何字以内」「結論を最初に」と具体的に頼むと、AIの直し方がはっきりします。

---

## レシピ17｜プレゼンのスライド構成を作る

**⏱ 60分 → 10分**

**こんな時：** プレゼン資料を作る前に、何枚目に何を書くか決めたい

```
以下の内容で、プレゼン資料のスライド構成を作ってください。

・テーマ：〔例：新しい勤怠管理システムの提案〕
・聞く人：〔例：取引先の総務部長〕
・時間：〔例：15分〕

条件：1枚ごとに「タイトル」と「載せる内容（箇条書き3つまで）」を書く／最後のスライドは次の行動につなげる
```

**出力例（抜粋）**

> **スライド2｜こんなお悩みはありませんか？**
> - 月末の勤怠集計に丸2日かかる
> - 打刻漏れの確認が手作業
> - 残業時間の把握が遅れる

**ポイント：** 「時間」を伝えると、ちょうどいい枚数で構成してくれます（目安は1分1枚）。

---

## レシピ18｜稟議書・申請書の「理由」欄を書く

**⏱ 30分 → 3分**

**こんな時：** 経費や備品の申請で、「理由」欄に何を書けば通るか分からない

```
以下の申請について、承認されやすい「申請理由」を書いてください。

・申請内容：〔例：営業部にノートPCを3台購入（計45万円）〕
・背景：〔例：今のPCが6年前のもので、動作が遅い〕
・効果：〔例：外出先で資料を作れるようになる〕

条件：200字以内／「現状の問題 → 導入の効果 → 費用に見合う理由」の順にする
```

**出力例（抜粋）**

> 現在使用しているPCは導入から6年が経過し、起動や資料作成に時間がかかっています。新しいPCの導入により、外出先でも資料作成が可能となり、1人あたり週2時間程度の業務時間削減が見込めます。

**ポイント：** 承認する人が気にするのは「その費用を出す価値があるか」です。順番を指定すると、そこに答える理由になります。

**注意：** 効果の数字は、AIが仮に置くことがあります。必ず自分で確かめた数字に直してください。

---

## レシピ19｜社内向けのお知らせ文

**⏱ 20分 → 2分**

**こんな時：** 全社や部署全体に、ルール変更やイベントを知らせたい

```
社内向けのお知らせ文を書いてください。

・内容：〔例：11月から経費精算の締め日が25日に変わる〕
・対象：〔例：全社員〕
・してほしい行動：〔例：10月分は従来どおり月末までに提出〕

条件：最初の2行で要点が分かるようにする／日付と期限は太字にする／300字以内
```

**出力例（抜粋）**

> **【重要】11月から経費精算の締め日が変わります**
> 11月分から、経費精算の締め日が**毎月25日**になります。
> なお、10月分は従来どおり**10月31日**までにご提出ください。

**ポイント：** 社内のお知らせは、ほとんどの人が最初の2行しか読みません。要点を先に出すよう指示しておきましょう。

---

## レシピ20｜「よくある質問（FAQ）」を作る

**⏱ 60分 → 10分**

**こんな時：** 同じ質問に何度も答えていて、FAQにまとめたい

```
以下の資料をもとに、「よくある質問（FAQ）」を10個作ってください。

・読む人：〔例：新しい経費精算システムを使う社員〕

条件：質問は読む人の言葉づかいで書く／答えは3行以内／資料に書かれていないことは答えず「要確認」と書く

〔ここに資料やマニュアルの本文を貼る〕
```

**出力例（抜粋）**

> **Q. 領収書をなくしてしまいました。どうすればいいですか？**
> A. 「領収書紛失届」を提出してください。上長の承認が必要です。

**ポイント：** 「資料にないことは『要確認』と書く」と指示しておくと、AIが話をでっち上げるのを防げます。

資料づくりのコツは、**AIに「たたき台」を作らせ、自分は「直す役」に回ること**です。
そして、数字や事実は必ず自分の目で確かめてください。
